### Critical Integration Gap

**Portal tile validation uses stale coordinates**

- **File:** `apps/game-server/src/game/game.gateway.ts`, line 825
- **Code:** `tiles[player.position.y][player.position.x]`
- **Problem:** `player.position.x/y` is only set at login/spawn/respawn, not updated during pixel movement. The actual position lives in `player.px/py`.
- **Impact:** Portal interaction unreliable for any player who has moved since session start.
- **Fix:** Replace with `pixelToTile(player.px, player.py)` — function already available in `@into-the-void/game-logic`.
- **Affects:** MAP-06, SYS-05
