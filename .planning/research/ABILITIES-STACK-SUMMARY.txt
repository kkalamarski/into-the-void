IMPLEMENTATION PATTERNS
-----------------------

Cooldowns:
  - Client: Zustand store with timestamp-based expiration
  - Visual: Phaser Graphics.slice() for pie-slice overlay
  - Server: Cooldown tracking for anti-cheat validation

Buffs:
  - Server: Map<playerId, Buff[]> with 10Hz tick expiration
  - Client: buffStore for UI display (buff icons)
  - Broadcast: Socket.IO events (buff:apply, buff:remove)

Energy:
  - Validation: Server checks energy before ability execution
  - Deduction: playerService.consumeEnergy(playerId, cost)
  - Broadcast: player:energy event updates client HUD

Abilities:
  - Definition: Items with effects array (energy_cost + deal_damage + cooldown)
  - Execution: AbilityService validates and broadcasts results
  - Flow: Client emit → Server validate → Broadcast results → Client render

DATA FLOW
