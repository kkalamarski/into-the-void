   ```typescript
   interface LiquidStore {
     active: boolean;
     liquidTileId: string | null;

     color: string | null;        // hex color string from tile definition
     speedMultiplier: number;
     damagePerTick: number;

     setLiquidState: (data: LiquidUpdatePayload) => void;

     clear: () => void;
   }
   ```
   - Create Zustand store with `create<LiquidStore>(...)`
   - Wire socket events at module level (same pattern as hazardStore):

   - `setDamage`: set `lastDamage` to damage value (consumed by EntityManager for floating number)
   - `setHeal`: set `lastHeal` to heal value
   - `clear()`: reset all to defaults
