**Add click-outside and Escape dismissal** with useEffect (same pattern as InventoryPanel):
```typescript
useEffect(() => {
  if (!contextMenu) return;
  const handleClickOutside = () => setContextMenu(null);
  const handleEscape = (e: KeyboardEvent) => {
    if (e.key === 'Escape') setContextMenu(null);
  };
  window.addEventListener('click', handleClickOutside);
  window.addEventListener('keydown', handleEscape);
  return () => {
    window.removeEventListener('click', handleClickOutside);
    window.removeEventListener('keydown', handleEscape);
  };
}, [contextMenu]);
```

**Add context menu handler:**
```typescript
const handleSenderContextMenu = (e: React.MouseEvent, msg: ChatMessage) => {
  e.preventDefault();
  // Don't show context menu for system messages or own messages
  if (msg.channel === 'system' || msg.senderId === currentPlayerId) return;

  // Position relative to chat panel
  const panelRect = (e.currentTarget as HTMLElement).closest('.chat-panel')?.getBoundingClientRect();
  const x = panelRect ? e.clientX - panelRect.left : e.clientX;
  const y = panelRect ? e.clientY - panelRect.top : e.clientY;

  setContextMenu({ x, y, senderId: msg.senderId, senderName: msg.senderName });
};
```

**Add context menu action handlers:**
```typescript
const handleMuteToggle = async () => {
  if (!contextMenu) return;
  if (mutedIds.has(contextMenu.senderId)) {
    await removeMute(contextMenu.senderId);
  } else {
    await addMute(contextMenu.senderId);
  }
  setContextMenu(null);
};

const handleBlockToggle = async () => {
  if (!contextMenu) return;
  if (blockedIds.has(contextMenu.senderId)) {
    await removeBlock(contextMenu.senderId);
  } else {
    await addBlock(contextMenu.senderId);
  }
  setContextMenu(null);
};

const handleWhisperTo = () => {
  if (!contextMenu) return;
  setWhisperTarget(contextMenu.senderName);
  switchChannel('whisper');
  setContextMenu(null);
};
```

**Render the context menu** just before the closing `</div>` of `.chat-panel`, after the form element:

```tsx
{contextMenu && (
  <div
    className="chat-context-menu"

    onClick={(e) => e.stopPropagation()}
  >
    <button onClick={handleWhisperTo}>

  </div>
)}
```

**Key behavior details:**
- Context menu only appears on right-click of sender names, NOT on timestamp or message text
- No context menu for system messages (channel === 'system') or the player's own messages (senderId === currentPlayerId)
- Mute/Unmute and Block/Unblock toggle labels based on current moderationStore state
- Whisper action sets the target name and switches to whisper tab
- Menu dismisses on: any click outside, Escape key, or clicking a menu item
- The `onClick={(e) => e.stopPropagation()}` on the menu prevents the click-outside handler from firing when clicking menu items before the async action completes
