   - Add `PERSISTENCE_THRESHOLD_MS = 60000` constant (1 minute - cooldowns >= this get persisted)
   - Modify `setCooldown()`: if `cooldownMs >= PERSISTENCE_THRESHOLD_MS`, also call `saveCooldown()` to DB
   - Add `loadCooldownsFromDb(playerId)` method: loads cooldowns from DB, populates in-memory map, returns list for emission

3. Handle home_recall effect in `useAbility()`:
   - After checking ability availability and cooldowns, before applying effects
   - If `abilityId === 'home_recall'`:
     - Check player not already in hub: `if (isHubZone(player.position.zoneId)) return { success: false, error: 'Already in hub' }`
     - Call `this.playerService.teleportToHub(playerId)`
     - Handle zone transition: emit `player:left` to old zone, emit `zone:state` to player for new zone
     - Set cooldown and return success
     - Skip normal effects loop (home_recall has no effects array)

4. Modify `handleDisconnect()`:
   - Keep current behavior (clears in-memory cooldowns)
   - DB-persisted cooldowns remain in database for reload on reconnect

5. Add `restoreCooldowns(playerId, socketId)` method:
   - Load from DB via `loadCooldownsFromDb()`
   - For each active cooldown, emit `ability:cooldown` event to socket

6. In `game.gateway.ts` `handleAuth()`:
   - After successful auth, before emitting `auth:success`
   - Call `this.abilityService.restoreCooldowns(player.id, client.id)` to restore and emit persistent cooldowns
