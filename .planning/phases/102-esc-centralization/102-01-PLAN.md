    **Create `apps/web/src/store/modalStackStore.ts`:**

    Zustand store (no immer needed — simple array operations). Shape:

    ```typescript
    interface ModalEntry {
      id: string;
      onClose: () => void;
    }

    interface ModalStackState {
      stack: ModalEntry[];
      push: (id: string, onClose: () => void) => void;
      pop: () => void;
      popById: (id: string) => void;
      peek: () => ModalEntry | undefined;
    }
    ```

    - `push`: Appends `{ id, onClose }` to the end of the `stack` array. If an entry with the same `id` already exists, do NOT push a duplicate (idempotent guard).
    - `pop`: Removes the last entry from `stack` (shallow copy with `slice(0, -1)`).
    - `popById`: Filters out the entry with matching `id` (for cleanup on unmount after pop already removed it — this is a no-op if the entry is gone).
    - `peek`: Returns `stack[stack.length - 1]` or `undefined`. Use `get()` not `set()`.

    No persistence (no `persist` middleware). This is ephemeral session state.

    **Create `apps/web/src/hooks/useModalStack.ts`:**

    ```typescript
    import { useEffect, useRef } from 'react';
    import { useModalStackStore } from '../store/modalStackStore';

    export function useModalStack(id: string, onClose: () => void): void {
      const push = useModalStackStore((s) => s.push);
      const popById = useModalStackStore((s) => s.popById);
      const onCloseRef = useRef(onClose);
      onCloseRef.current = onClose;

      useEffect(() => {
        push(id, () => onCloseRef.current());
        return () => popById(id);
      }, [id, push, popById]);
    }
    ```

    Key design decisions:
    - `id` is a **well-known string** passed by the caller (e.g., `'game-menu'`, `'inventory'`), NOT auto-generated. This enables hotkey handlers to check `peek()?.id` for toggle gating (required by CONTEXT.md decision: "Hotkey toggle only works when that modal is the topmost").
    - `onCloseRef` prevents stale closures — the registered callback always calls the latest `onClose` without re-registering the effect.
    - The `useEffect` deps include `id`, `push`, `popById` — Zustand selectors are stable references, so this only runs once on mount (and cleanup on unmount).
