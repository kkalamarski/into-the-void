export interface TileDefinition {

**Naming convention:** `{HUB}_{TYPE}` for exports, `{hub}_{type}` for string IDs.
**textureKey convention:** `tile_{id}` (e.g., `tile_canopy_floor`).

**Tile type specifications (same for all 4 hubs):**

| Type | ID suffix | isBlocking | movementSpeed | defaultElevation | Description |
|------|-----------|------------|---------------|------------------|-------------|
| Main floor | `_floor` | false | 1.0 | 0 | Primary room surface |
| Wall | `_wall` | true | 0 | 2 | Solid wall, impassable |
| Door | `_door` | false | 1.0 | 0 | Doorway between rooms |
| Corridor floor | `_corridor` | false | 1.0 | 0 | Hallway surface |
| Decoration | `_decoration` | true | 0 | 1 | Consoles/machinery/vegetation/cargo — blocking obstacle |
| Accent floor | `_accent` | false | 0.9 | 0 | Grating/moss/glass/patch — slightly slower |
| Window wall | `_window` | true | 0 | 2 | Viewport/window — blocking but semi-transparent concept |
| Hazard | `_hazard` | false | 0.7 | 0 | Environmental hazard — slow + damage hook |

**Canopy Station (Verdant) palette** — bioluminescent green/blue, organic:
- Floor: `0x1a3a2a` (dark green), Accent: Slightly lighter green `0x2a5a3a`

- Door: `0x2a6a4a` (glowing archway), Corridor: `0x1a3528` (mossy corridor)
- Decoration: `0x3a8a5a` (glowing console/vegetation), Hazard: `0x44bb66` (spore vent)
- Hazard hook: `{ type: 'damage', amount: 2 }` — toxic spores

**Ironhold Station (Helix) palette** — industrial gray/rust/orange:
- Floor: `0x3a3a3a` (metal plate), Accent: `0x4a3a2a` (rust-stained grating)
- Wall: `0x2a2a2a` (heavy steel), Window: `0x4a4a4a` (reinforced viewport)
- Door: `0x5a4a3a` (blast door), Corridor: `0x353535` (metal corridor)
- Decoration: `0x6a5a3a` (machinery), Hazard: `0xcc6622` (steam vent)
- Hazard hook: `{ type: 'damage', amount: 3 }` — scalding steam

**Meridian Station (Nexus) palette** — corporate silver/white/blue:
- Floor: `0xb0b8c0` (polished silver), Accent: `0x88a0bb` (glass panel floor)
- Wall: `0x8090a0` (brushed steel), Window: `0x90a8c0` (panoramic viewport)
- Door: `0xa0b0c8` (sliding glass door), Corridor: `0xa0a8b0` (clean corridor)
- Decoration: `0x6688aa` (holographic terminal), Hazard: `0x4488ff` (data stream)
- Hazard hook: `{ type: 'slow', duration: 3000, multiplier: 0.5 }` — data interference

**Salvage Station (Unaffiliated) palette** — patchwork/mixed/scrap:
- Floor: `0x5a5040` (patched metal), Accent: `0x6a5a3a` (mismatched grating)
- Wall: `0x4a4030` (scrap wall), Window: `0x5a5a4a` (salvaged porthole)
- Door: `0x6a6050` (cobbled door), Corridor: `0x504838` (duct-taped corridor)
- Decoration: `0x7a6a4a` (cargo pile), Hazard: `0xaa4422` (exposed wiring)
- Hazard hook: `{ type: 'damage', amount: 2 }` — electrical shock
