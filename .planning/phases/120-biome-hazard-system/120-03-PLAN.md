**1. Create `apps/game-server/src/game/hazard.service.ts`:**

```typescript
@Injectable()
export class HazardService {
  private hazardStates: Map<string, HazardState> = new Map(); // playerId -> state
  private server: Server | null = null;

  constructor(
    private readonly playerService: PlayerService,
    private readonly inventoryService: InventoryService,
  ) {}

  setServer(server: Server): void { this.server = server; }
```

**Methods:**

a. `onPlayerEnteredZone(playerId: string, zoneId: string, biomeType: BiomeType): void`
   - If `isHubZone(zoneId)`: call `clearHazardState(playerId, 'entered_hub')` and return (HAZD-09)
   - Call `getHazardForBiome(biomeType)`
   - If null (Tier I): call `clearHazardState(playerId, 'left_zone')` and return
   - Compute protection: call `getPlayerProtection(playerId, hazardConfig.hazardType)`
   - Create HazardState: `{ playerId, hazardType, config, enteredAt: Date.now(), lastTickAt: 0, protectionPercent, stackCount: 0, lastStackAt: Date.now() }`
   - Set in Map
   - Emit `hazard:update` to player socket with `active: true, inGracePeriod: true, ...`

b. `onPlayerEquipmentChanged(playerId: string): void`
   - If player has active hazard state, recalculate protection
   - Update `protectionPercent` in state
   - Emit `hazard:update` to player socket

c. `processHazardTick(zoneId: string): void` — **CRITICAL: synchronous reads only**
   - Get players in zone from playerService
   - For each player with a hazardState in the Map:
     - Skip if player.isDead or player health <= 0
     - Call `shouldApplyHazardTick(state, now)`
     - If true:
       - Calculate damage via `calculateHazardDamage(state.config, player.maxHealth, state.protectionPercent)`
       - If damage > 0: reduce player.health, clamp to 0, emit `hazard:damage`, emit `player:health`
       - Calculate debuff via `calculateHazardDebuff(...)` — apply as temporary stat modifier
       - Update `lastTickAt` in state
     - Handle Tier IV stacking: if `shouldIncreaseStack(state, now)`: increment stackCount, update lastStackAt, emit updated `hazard:update`
     - Check grace period: if still in grace, emit `hazard:update` with `inGracePeriod: true`
       - When grace period ends (first tick after grace): emit `hazard:update` with `inGracePeriod: false`

d. `clearHazardState(playerId: string, reason: 'left_zone' | 'entered_hub' | 'fully_protected'): void`
   - Delete from Map
   - Emit `hazard:clear` to player socket
   - Emit `hazard:update` with `active: false`

e. `getPlayerProtection(playerId: string, hazardType: HazardType): number`
   - Get inventory from inventoryService
   - Call `effectiveStats()` on equipment
   - Return `stats.hazardProtection[hazardType] ?? 0`
   - IMPORTANT: Also check for active consumable buffs (from buff system) — look for `hazardProtection_{hazardType}` in active buffs and add to equipment protection
   - Cap at 100

f. `onPlayerDisconnect(playerId: string): void`
   - Delete from Map (cleanup)
