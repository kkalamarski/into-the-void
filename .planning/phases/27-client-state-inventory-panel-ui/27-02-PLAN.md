Create `SortableSlot` component (internal):
```typescript
interface SortableSlotProps {
  instanceId: string;
  itemId: string;
  quantity: number;
  onContextMenu: (e: React.MouseEvent, instanceId: string) => void;
}

function SortableSlot({ instanceId, itemId, quantity, onContextMenu }: SortableSlotProps) {
  const { attributes, listeners, setNodeRef, transform, transition, isDragging } = useSortable({
    id: instanceId,
  });
  const itemDef = ItemRegistry.get(itemId);
  const style = {
    transform: CSS.Transform.toString(transform),
    transition,
    opacity: isDragging ? 0.5 : 1,
    borderColor: RARITY_COLORS[itemDef.rarity],
  };

  return (
    <div
      ref={setNodeRef}
      className="inventory-slot inventory-slot--filled"
      style={style}
      {...attributes}
      {...listeners}
      onContextMenu={(e) => onContextMenu(e, instanceId)}
    >
      <div className="slot-icon" style={{ backgroundColor: `#${itemDef.color.toString(16).padStart(6, '0')}` }} />
      {quantity > 1 && <span className="slot-quantity">{quantity}</span>}
    </div>
  );
}
```

Create `InventoryPanel` component:
- Use `useInventoryStore()` to get `inventory`, `pendingReorder`
- Use `useGameStore()` to get `toggleInventory`
- State: `contextMenu: { x: number; y: number; instanceId: string } | null`
- `sensors = useSensors(useSensor(PointerSensor, { activationConstraint: { distance: 8 } }))`

Early return `null` if `!inventory`

Sort items by slot: `const sortedItems = [...inventory.items].sort((a, b) => a.slot - b.slot)`
Create slots array for 0 to maxSlots-1, mapping to item or null
Get sortable IDs: `sortedItems.map(i => i.instanceId)`

`handleDragEnd`:
- If pendingReorder, return
- If no over or active.id === over.id, return
- Find fromItem and toItem by instanceId
- Call `useInventoryStore.getState().setPendingReorder(true)`
- Call `gameSocket.emit('inventory:reorder', { fromSlot: fromItem.slot, toSlot: toItem.slot })`

`handleContextMenu`: set contextMenu state with x, y, instanceId

`handleDrop`:
- Get instanceId from contextMenu
- Call `gameSocket.emit('inventory:drop', { instanceId, quantity: 1 })`
- Clear contextMenu

`handleUse`:
- Get instanceId from contextMenu
- Call `gameSocket.emit('inventory:use', { instanceId })`
- Clear contextMenu

useEffect for click-outside to clear contextMenu

Render structure:
```jsx
<div className="inventory-panel ui-panel">
  <div className="inventory-header">
    <span>Inventory ({inventory.items.length}/{inventory.maxSlots})</span>
    <button className="close-btn" onClick={toggleInventory}>&times;</button>
  </div>
  <DndContext sensors={sensors} collisionDetection={closestCenter} onDragEnd={handleDragEnd}>
    <SortableContext items={sortableIds} strategy={rectSortingStrategy}>
      <div className="inventory-grid" style={{ pointerEvents: pendingReorder ? 'none' : 'auto' }}>
        {slots.map((item, i) =>
          item ? (
            <SortableSlot key={item.instanceId} {...item} onContextMenu={handleContextMenu} />
          ) : (
            <div key={`empty-${i}`} className="inventory-slot inventory-slot--empty" />
          )
        )}
      </div>
    </SortableContext>
  </DndContext>
  {contextMenu && (
    <div className="context-menu" style={{ left: contextMenu.x, top: contextMenu.y }}>
      <button onClick={handleUse}>Use</button>
      <button onClick={handleDrop}>Drop</button>
    </div>
  )}
</div>
```
