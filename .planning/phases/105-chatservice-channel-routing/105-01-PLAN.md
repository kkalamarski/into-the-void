```typescript
import { Injectable } from '@nestjs/common';
import { Server, Socket } from 'socket.io';
import { ChatMessage, ChatChannel } from '@into-the-void/shared-types';
import { isPositionVisible, DEFAULT_VISIBILITY_RANGE } from '@into-the-void/game-logic';
import { isBlocked } from '@into-the-void/database';
import { PlayerService } from './player.service';
import { DatabaseService } from '../database/database.service';
```

**Class structure:**

```typescript
@Injectable()
export class ChatService {
  private server: Server | null = null;

  constructor(
    private readonly playerService: PlayerService,
    private readonly databaseService: DatabaseService,
  ) {}

  setServer(server: Server): void {
    this.server = server;
  }

  async handleMessage(client: Socket, senderId: string, senderName: string, channel: ChatChannel, text: string, targetId?: string): Promise<void> {
    // Build the ChatMessage object
    const message: ChatMessage = {
      id: crypto.randomUUID(),
      senderId,
      senderName,
      message: text,
      channel,
      timestamp: Date.now(),
    };

    switch (channel) {
      case 'zone':
        this.sendZone(client, message);
        break;
      case 'global':
        this.sendGlobal(message);
        break;
      case 'faction':
        this.sendFaction(client, senderId, message);
        break;
      case 'local':
        this.sendLocal(senderId, message);
        break;
      case 'whisper':
        await this.sendWhisper(client, senderId, message, targetId);
        break;
    }
  }
```

**Channel routing methods (all private):**

1. **`private sendZone(client: Socket, message: ChatMessage): void`**
   - Get the sender player via `this.playerService.getPlayerById(message.senderId)`. If not found, return.
   - Emit to the sender's zone room: `this.server!.to(player.position.zoneId).emit('chat:message', message);`
   - This reuses the existing zone room that players already join on auth/zone-transition.

2. **`private sendGlobal(message: ChatMessage): void`**
   - `this.server!.emit('chat:message', message);`
   - Broadcasts to all connected sockets (all authenticated players).

3. **`private sendFaction(client: Socket, senderId: string, message: ChatMessage): void`**
   - Get the sender player via `this.playerService.getPlayerById(senderId)`. If not found, return.
   - Get the faction: `player.faction`. If faction is `'neutral'` or `'unaffiliated'`, silently return (neutral players have no faction chat).
   - Emit to the faction room: `this.server!.to(`faction:${player.faction}`).emit('chat:message', message);`
   - The faction room `faction:<factionId>` will be joined in Plan 02 during auth and preserved across zone transitions.

4. **`private sendLocal(senderId: string, message: ChatMessage): void`**
   - Get the sender player via `this.playerService.getPlayerById(senderId)`. If not found, return.
   - Get all players in the same zone: `this.playerService.getPlayersInZone(player.position.zoneId)`.
   - For each player in the zone, check `isPositionVisible(player.position, otherPlayer.position, DEFAULT_VISIBILITY_RANGE)`.
   - For each player within range, get their socket ID via `this.playerService.getSocketByPlayerId(otherPlayer.id)` and emit: `this.server!.to(socketId).emit('chat:message', message)`.
   - Also emit to the sender's own socket if not already included (the sender should see their own local message).
   - NOTE: The sender is always included because `isPositionVisible` returns true for same-position (distance 0).

5. **`private async sendWhisper(client: Socket, senderId: string, message: ChatMessage, targetId?: string): Promise<void>`**
   - If `!targetId`, emit a system error to the sender and return:
     ```typescript
     client.emit('chat:message', {
       id: crypto.randomUUID(),
       senderId: 'system',
       senderName: 'System',
       message: 'Whisper requires a target player.',
       channel: 'system' as ChatChannel,
       timestamp: Date.now(),
     });
     return;
     ```
   - Look up target player: `this.playerService.getPlayerById(targetId)`.
   - If target is not online (undefined), emit system notice to sender: `'That player is not online.'` and return. This addresses the STATE.md concern about whisper to offline player.
   - Check block status: `const blocked = await isBlocked(this.databaseService.getClient(), senderId, targetId);`
     - `isBlocked(db, senderId, targetId)` returns true if `targetId` has blocked `senderId` (the sender is in the target's block list).
   - If blocked, emit system notice to sender: `'That player is not accepting whispers from you.'` and return. Do NOT deliver the message to the target.
   - If not blocked, get target socket: `this.playerService.getSocketByPlayerId(targetId)`.
   - Emit to target socket: `this.server!.to(targetSocket).emit('chat:message', message);`
   - Echo back to sender: `client.emit('chat:message', message);` (so the sender sees their own whisper in the UI).

**Important implementation notes:**
- Use `crypto.randomUUID()` for message IDs (same as existing gateway code).
- The `setServer()` method follows the same pattern as `PlayerService.setServer()`, `CombatService.setServer()`, etc. It will be called from `GameGateway.afterInit()` in Plan 02.
- All routing methods should guard against `this.server` being null. If null, return early.
