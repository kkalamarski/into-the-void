**Labels (for Traefik's own dashboard routing):**
- Route `traefik.${DOMAIN}` to internal dashboard API
- Secure with basic auth middleware
- Use HTTPS with letsencrypt resolver

**Resource limits:**

<task type="auto">
  <name>Task 3: Update docker-stack.yml with HTTPS routers</name>
  <files>docker-stack.yml</files>
  <action>
Update the existing Traefik labels in docker-stack.yml to enable HTTPS:

**For all services (api, game-server, web):**
Add to existing labels:
- `traefik.http.routers.{service}.entrypoints=websecure` - use HTTPS entrypoint
- `traefik.http.routers.{service}.tls=true` - enable TLS
- `traefik.http.routers.{service}.tls.certresolver=letsencrypt` - use Let's Encrypt

**For web service specifically:**
- Add HTTP to HTTPS redirect middleware:
  - `traefik.http.middlewares.redirect-to-https.redirectscheme.scheme=https`
  - `traefik.http.routers.web-http.rule=Host(\`play.${DOMAIN}\`)`
  - `traefik.http.routers.web-http.entrypoints=web`
  - `traefik.http.routers.web-http.middlewares=redirect-to-https`

**For game-server (WebSocket):**
Keep existing sticky session labels, they work with HTTPS.
Add WebSocket-specific headers if needed (Traefik v3 handles WebSocket automatically).

Note: The existing router rules (Host matching) and load balancer ports remain unchanged.
  </action>

- docker-stack.yml has `tls.certresolver=letsencrypt` on all three services
- docker-stack.yml has `entrypoints=websecure` on all three services
- web service has HTTP redirect middleware
- Sticky sessions preserved on game-server
  </verify>
  <done>
All services configured for HTTPS with Let's Encrypt certificates and HTTP redirect.
