# Plan 157-02: Liquid Tile Rendering — Procedural Textures & Overlay Layer

## Goal
Client renders liquid tiles as half-height isometric slabs at fixed elevation 0. Translucent liquids show terrain beneath; opaque liquids fully cover terrain. Liquid tiles use procedurally generated textures from the tile strategy system.

## Must-Haves (goal-backward)
- All 16 liquid tiles have palettes in BIOME_PALETTES and bake procedural textures
- Liquid tiles render as half-height slabs (they already have `renderHeightMultiplier: 0.5`)
- Liquid overlay renders ON TOP of the terrain tile at elevation 0 (fixed sea level)
- Translucent liquids: terrain tile visible beneath (liquid rendered with alpha)
- Opaque liquids: terrain tile fully covered (liquid at alpha 1.0)
- No collision change — liquids don't block player movement

## Context
- Phase 156 defined all 16 liquid tiles with `color`, `liquidOpacity` ('translucent' | 'semi-opaque' | 'opaque'), and `renderHeightMultiplier: 0.5`
- ProceduralTileGenerator bakes textures by iterating BIOME_PALETTES entries
- Each tile gets a palette in `tile-palettes.ts` and optionally a render strategy for accents
- TileRenderer.createTileWithElevationWorld() creates cube sprites stacked from ground to visual elevation
- WorldScene.renderChunk() iterates tiles[][] and creates tile containers
- ChunkData now includes `liquidTiles?: (string | null)[][]` from Plan 157-01
- The existing cube geometry uses SH=64 for side height. Half-height liquid slabs should use SH/2=32 for sides
- ELEVATION_HEIGHT_STEP is 64px. Half-height means 32px side faces

<task id="2" title="Create LiquidTileStrategy and register it">
<context>
Tile strategies add accent details to the top face during texture baking.
Liquid tiles should have subtle surface effects (ripples for water-like, glow lines for energy-like).
The strategy pattern: extend AbstractTileRenderStrategy, list handledTileIds, implement drawTopAccents.
</context>
<actions>
1. Create `apps/web/src/game/rendering/tile-strategies/LiquidTileStrategy.ts`:
   ```typescript
   import Phaser from 'phaser';
   import type { TilePalette } from './types';
   import { AbstractTileRenderStrategy } from './AbstractTileRenderStrategy';
   import { detailRandom } from './tile-palettes';

   /**
    * Renders accent details for liquid surface tiles.
    * Water-like liquids get ripple arcs; energy/magma liquids get glow lines.
    */
   export class LiquidTileStrategy extends AbstractTileRenderStrategy {
     readonly handledTileIds = [
       'void_ether', 'luminous_sap', 'seawater', 'ancient_runoff',
       'spore_sludge', 'miasma_bile', 'mineral_slurry', 'deep_seawater',
       'luminous_nectar', 'magma', 'resonant_fluid', 'glacial_melt',
       'impact_brine', 'abyssal_water', 'silicon_solution', 'rift_plasma',
     ] as const;

     drawTopAccents(
       g: Phaser.GameObjects.Graphics,
       tileId: string,
       palette: TilePalette,
       seed: number,
     ): void {
       const accentColor = palette.accent;
       const isEnergy = tileId === 'magma' || tileId === 'rift_plasma' || tileId === 'void_ether' || tileId === 'resonant_fluid';

       if (isEnergy) {
         // Energy liquids: glowing veins/cracks on surface
         g.lineStyle(1.5, accentColor, 0.35);
         for (let i = 0; i < 3; i++) {
           const start = this.topDiamondPoint(seed, i + 100);
           const end = this.topDiamondPoint(seed, i + 200);
           g.beginPath();
           g.moveTo(start.x, start.y);
           const mid = this.topDiamondPoint(seed, i + 150);
           g.lineTo(mid.x, mid.y);
           g.lineTo(end.x, end.y);
           g.strokePath();
         }
       } else {
         // Water-like liquids: concentric ripple arcs
         g.lineStyle(1, accentColor, 0.2);
         for (let i = 0; i < 3; i++) {
           const pos = this.topDiamondPoint(seed, i + 185);
           const r = 8 + detailRandom(seed, i + 190) * 6;
           g.beginPath();
           g.arc(pos.x, pos.y, r, 0, Math.PI, false);
           g.strokePath();
         }
       }
     }
   }
   ```
2. Open `apps/web/src/game/rendering/tile-strategies/index.ts`
3. Import LiquidTileStrategy
4. Add `registerStrategy(new LiquidTileStrategy());` in `initTileStrategies()`
</actions>
<verify>
- LiquidTileStrategy handles all 16 liquid tile IDs
- Strategy is registered in initTileStrategies()
- Energy liquids get glow lines, water-like get ripple arcs
</verify>

<task id="3" title="Bake half-height liquid textures in ProceduralTileGenerator">
<context>
`apps/web/src/game/rendering/ProceduralTileGenerator.ts` iterates BIOME_PALETTES and bakes 256x256 cube textures.
Liquid tiles need HALF-HEIGHT cubes: the side faces should be SH/2 = 32px tall instead of 64px.
The cube geometry constants are: HW=128, HH=64, SH=64.
For half-height: side faces go from y=128 to y=160 (32px) instead of y=128 to y=192 (64px).
The canvas should still be 256x256 but the bottom portion will be empty (transparent).
</context>
<actions>
1. Open `apps/web/src/game/rendering/ProceduralTileGenerator.ts`
2. Import `TileRegistry` from `@into-the-void/tiles` (if not already imported)
3. In the `bakeAllTextures()` method, after iterating BIOME_PALETTES, detect liquid tiles and bake them with half-height geometry:
   - Check if a tile is liquid by looking up `TileRegistry.get(tileId)?.isLiquid`
   - For liquid tiles, call a new method `bakeLiquidTile()` that draws half-height cube geometry
4. Create `bakeLiquidTile()` method:
   - Same top diamond as normal tiles: (128,0) -> (256,64) -> (128,128) -> (0,64)
   - Half-height south face: (0,64) -> (128,128) -> (128,160) -> (0,96) — only 32px tall
   - Half-height east face: (128,128) -> (256,64) -> (256,96) -> (128,160) — only 32px tall
   - Use the same palette and strategy accent system
   - The SH for liquid is `SH / 2 = 32`
5. Alternative simpler approach: modify `bakeTile()` to accept an optional `sideHeight` parameter. Default to SH (64). For liquid tiles, pass SH/2 (32). This avoids duplicating the entire bake method.
   - In `bakeTile()`, replace hardcoded SH references with the parameter
   - In `bakeAllTextures()`, when iterating palettes, check isLiquid and pass appropriate side height
</actions>

<task id="4" title="Render liquid overlay layer in WorldScene.renderChunk()">
<context>
`apps/web/src/game/scenes/WorldScene.ts` `renderChunk()` iterates tiles[][] and creates tile containers.
Now ChunkData includes `liquidTiles?: (string | null)[][]`.
Liquid tiles render as a SECOND sprite on top of the terrain tile at elevation 0.
Translucent liquids need alpha < 1.0; opaque liquids use alpha 1.0.
`liquidOpacity` is on the TileDefinition: 'translucent' | 'semi-opaque' | 'opaque'.
</context>
<actions>
1. Open `apps/web/src/game/scenes/WorldScene.ts`
2. Import `TileRegistry` from `@into-the-void/tiles` (if not already)
3. In `renderChunk()`, after the existing tile rendering loop, add a second pass for liquid tiles:
   ```typescript
   // Render liquid overlay tiles
   if (chunkData.liquidTiles) {
     for (let y = 0; y < mapHeight; y++) {
       for (let x = 0; x < mapWidth; x++) {
         const liquidTileId = chunkData.liquidTiles[y]?.[x];
         if (!liquidTileId) continue;

         const worldX = chunkGridX + x;
         const worldY = chunkGridY + y;
         const liquidDef = TileRegistry.get(liquidTileId);

         // Liquid renders at fixed elevation 0 (sea level)
         const liquidElevation = 0;
         const screenPos = this.isoTransform!.gridToScreen(worldX, worldY);
         const elevationOffset = liquidElevation * ELEVATION_HEIGHT_STEP;

         // Create liquid sprite using procedural texture
         const textureKey = `proc_tile_${liquidTileId}`;
         const hasTexture = this.textures.exists(textureKey);

         let liquidSprite: Phaser.GameObjects.Image | Phaser.GameObjects.Rectangle;
         if (hasTexture) {
           liquidSprite = this.add.image(screenPos.x, screenPos.y - elevationOffset, textureKey);
           liquidSprite.setOrigin(0.5, 0.25);
         } else {
           // Fallback: colored rectangle
           liquidSprite = this.add.rectangle(screenPos.x, screenPos.y - elevationOffset, 256, 128, liquidDef.color);
           liquidSprite.setOrigin(0.5, 0.5);
         }

         // Set alpha based on liquidOpacity
         const opacity = liquidDef.liquidOpacity;
         if (opacity === 'translucent') {
           liquidSprite.setAlpha(0.5);
         } else if (opacity === 'semi-opaque') {
           liquidSprite.setAlpha(0.75);
         } else {
           // opaque
           liquidSprite.setAlpha(1.0);
         }

         // Depth: slightly above terrain at same elevation for correct layering
         const depth = this.isoTransform!.calculateDepth(worldX, worldY, liquidElevation) + 0.1;
         liquidSprite.setDepth(depth);

         chunkTileArray.push(liquidSprite as any);
       }
     }
   }
   ```
4. IMPORTANT: The liquid sprite must sit on top of the terrain tile. Since terrain at elevation 0 is already rendered, the liquid just needs a slightly higher depth value (+0.1) at the same screen position.
5. For opaque liquids, the terrain tile beneath is still rendered but fully covered by the opaque liquid sprite — this is fine visually.
6. The liquidSprite uses `proc_tile_{liquidTileId}` as texture key, matching ProceduralTileGenerator's naming convention.
</actions>
<verify>

- Liquid renders as a half-height slab sitting at elevation 0
- Translucent liquids (alpha 0.5): terrain tile visible beneath
- Semi-opaque liquids (alpha 0.75): terrain partially visible
- Opaque liquids (alpha 1.0): terrain tile fully covered
- Player can walk through liquid tiles (no collision change)
- `pnpm build` succeeds
</verify>
