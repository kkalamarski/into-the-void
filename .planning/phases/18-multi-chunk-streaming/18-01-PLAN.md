    Modify ZonesService to use LRU cache instead of Map:

    1. Add import at top:
       ```typescript

       ```

    2. Replace the zones Map declaration:
       ```typescript
       // OLD:

       // NEW:
       private zones: LRUCache<string, ZoneState>;
       ```

    3. Initialize in constructor (after worldSeed):
       ```typescript
       this.zones = new LRUCache<string, ZoneState>({
         max: 500, // Max chunks in memory (supports ~250 concurrent players)
         ttl: 5 * 60 * 1000, // 5 minute TTL for inactive chunks
         updateAgeOnGet: true, // Refresh TTL on access
         updateAgeOnHas: false, // Don't refresh on existence check
         dispose: (value, key) => {
           console.log(`[ZonesService] Evicted chunk ${key}`);
         },
       });
       ```

    4. Remove the cleanup interval from onModuleInit:
       ```typescript
       // DELETE this line:
       setInterval(() => this.cleanupUnusedZones(), 60000);
       ```

    5. Delete the cleanupUnusedZones method entirely (LRU handles eviction).

    6. Remove lastAccessed from ZoneState interface (LRU tracks this internally):
       ```typescript
       interface ZoneState {
         chunk: ChunkData;
         entities: Map<string, Entity>;
         // Remove: lastAccessed: number;
       }
       ```

    7. Update loadZone to not set lastAccessed:
       ```typescript
       const zoneState: ZoneState = {
         chunk,
         entities,
         // Remove: lastAccessed: Date.now(),
       };
       ```

    8. Remove `zoneState.lastAccessed = Date.now();` from getChunk, getZoneEntities, and getEntity methods (LRU does this automatically via updateAgeOnGet).

    Note: LRU cache API is nearly identical to Map (get, set, has, delete, size work the same), so other code remains unchanged.
