**2. Create pixel-distance module** (`packages/game-logic/src/movement/pixel-distance.ts`):

Import `TILE_SIZE_PX` from `./pixel-validation` (created in Plan 01).

**Range constants as tile multiples:**
```typescript
export const MELEE_RANGE_PX       = 0.5  * TILE_SIZE_PX;  // 64 px  — half tile, melee reach
export const GATHER_RANGE_PX      = 1.5  * TILE_SIZE_PX;  // 192 px — 1.5 tiles, gathering/interaction
export const NPC_INTERACT_RANGE_PX = GATHER_RANGE_PX;      // Same as gather — consistent "close enough"
export const AGGRO_RADIUS_PX      = 4.0  * TILE_SIZE_PX;  // 512 px — 4 tiles, creature aggro
export const LEASH_RADIUS_PX      = 8.0  * TILE_SIZE_PX;  // 1024 px — 8 tiles, creature leash
```

**pixelDistanceTo:** Euclidean distance between two pixel positions.
```typescript
export function pixelDistanceTo(ax: number, ay: number, bx: number, by: number): number {
  const dx = bx - ax;
  const dy = by - ay;
  return Math.sqrt(dx * dx + dy * dy);
}
```

**tileToPixelCenter:** Returns center of tile in grid pixel space. Uses `(tileX + 0.5) * TILE_SIZE_PX` convention per RESEARCH.md Open Question #1 recommendation.
```typescript
export function tileToPixelCenter(tileX: number, tileY: number): { px: number; py: number } {
  return {
    px: (tileX + 0.5) * TILE_SIZE_PX,
    py: (tileY + 0.5) * TILE_SIZE_PX,
  };
}
```

**pixelToTile:** Converts pixel position to tile grid coordinates (floored integers).
```typescript
export function pixelToTile(px: number, py: number): { tileX: number; tileY: number } {
  return {
    tileX: Math.floor(px / TILE_SIZE_PX),
    tileY: Math.floor(py / TILE_SIZE_PX),
  };
}
```

Add JSDoc comments to all exports explaining units and conventions.

**3. Create pixel-distance tests** (`packages/game-logic/src/movement/pixel-distance.test.ts`):

Test cases:
- `pixelDistanceTo(0, 0, 128, 0)` equals 128 (one tile horizontal)
- `pixelDistanceTo(0, 0, 0, 128)` equals 128 (one tile vertical)
- `pixelDistanceTo(0, 0, 128, 128)` approximately equals `128 * Math.sqrt(2)` (diagonal)
- `pixelDistanceTo(100, 100, 100, 100)` equals 0 (same point)
- `tileToPixelCenter(0, 0)` returns `{ px: 64, py: 64 }` (center of first tile)
- `tileToPixelCenter(1, 0)` returns `{ px: 192, py: 64 }`
- `tileToPixelCenter(0, 1)` returns `{ px: 64, py: 192 }`
- `pixelToTile(64, 64)` returns `{ tileX: 0, tileY: 0 }` (center of tile 0,0)
- `pixelToTile(128, 0)` returns `{ tileX: 1, tileY: 0 }` (exactly on tile boundary)
- `pixelToTile(127, 127)` returns `{ tileX: 0, tileY: 0 }` (just before boundary)
- Range constants: `MELEE_RANGE_PX` equals `0.5 * 128`, `GATHER_RANGE_PX` equals `1.5 * 128`, `NPC_INTERACT_RANGE_PX` equals `GATHER_RANGE_PX`, `AGGRO_RADIUS_PX` equals `4 * 128`, `LEASH_RADIUS_PX` equals `8 * 128`
- Roundtrip: `pixelToTile(tileToPixelCenter(3, 5).px, tileToPixelCenter(3, 5).py)` returns `{ tileX: 3, tileY: 5 }`
