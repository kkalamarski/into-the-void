**Constants:**
```typescript
/** Logical pixel size of one grid tile. Equals ISO_TILE_WIDTH/2 = tileWidthHalf. */
export const TILE_SIZE_PX = 128;

/** Max player speed in pixels per second at base (1.0) multiplier. 128 px/s = 1 tile per second. */
export const PLAYER_SPEED_PX = TILE_SIZE_PX;

/** Diagonal normalization factor: 1/sqrt(2) ≈ 0.7071. Applied when both X and Y input active. */
export const DIAGONAL_NORMALIZATION = 1 / Math.sqrt(2);

/** Player AABB hitbox (square, anchored at feet/bottom-center of sprite). */
export const PLAYER_HITBOX = {
  width: Math.round(TILE_SIZE_PX * 0.5),   // 64 px
  height: Math.round(TILE_SIZE_PX * 0.5),  // 64 px
} as const;
```

**KeyState interface:**
```typescript
export interface KeyState {
  up: boolean;
  down: boolean;
  left: boolean;
  right: boolean;
}
```

**velocityFromKeys implementation:**
1. Compute raw direction: `dirX` = (right ? 1 : 0) - (left ? 1 : 0), `dirY` = (down ? 1 : 0) - (up ? 1 : 0)
2. If both dirX and dirY are non-zero, multiply both by `DIAGONAL_NORMALIZATION` — this is MOVE-02
3. Scale by `PLAYER_SPEED_PX * dt * speedMultiplier`
4. Return `{ vx, vy }`

**resolvePixelCollision implementation:**
The function takes `(px, py, vx, vy, isSolid)` and returns `{ px, py }`.

Wall sliding with separate X/Y passes (X-first):

1. **Try X move:** Compute candidate position `(px + vx, py)`. Check the 4 corners of the AABB hitbox at the candidate position. The hitbox is anchored at feet (bottom-center), so corners are:
   - Top-left: `(px - PLAYER_HITBOX.width/2, py - PLAYER_HITBOX.height)`
   - Top-right: `(px + PLAYER_HITBOX.width/2 - 1, py - PLAYER_HITBOX.height)`
   - Bottom-left: `(px - PLAYER_HITBOX.width/2, py - 1)`
   - Bottom-right: `(px + PLAYER_HITBOX.width/2 - 1, py - 1)`

   Convert each corner pixel to tile coords via `Math.floor(cornerPx / TILE_SIZE_PX)`. If any tile is solid, zero the X component.

2. **Try Y move:** Same logic but move `(resolvedPx, py + vy)`. If any corner tile is solid, zero the Y component.

3. Return final `{ px: resolvedPx, py: resolvedPy }`.

IMPORTANT: The `-1` on right/bottom edges prevents the hitbox from bleeding into the next tile when exactly on a tile boundary.

**validatePixelSpeed implementation:**
1. Compute distance: `Math.sqrt((toPx - fromPx)^2 + (toPy - fromPy)^2)`
2. Compute max allowed: `PLAYER_SPEED_PX * dt * speedMultiplier * 1.1` (10% tolerance for network jitter)
3. Return `distance <= maxAllowed`

Keep the module as pure functions with no side effects, no class instances, no browser API dependencies.
