  **Component Implementation:**

  1. **Imports:** React, useState, useEffect, useRef, useCraftingStore, useGameStore, useInventoryStore, useModalStack, useDraggablePanel, ItemRegistry, ItemIcon, getQualityThresholds from `@into-the-void/game-logic`, GiAnvil (or similar) from react-icons/gi, and CraftingPanel.css.

  2. **On mount:** Call `requestRecipes()` from craftingStore. Also disable Phaser keyboard input (same pattern as EquipmentPanel: `worldScene.setKeyboardEnabled(false)` in useEffect, restore on unmount).

  3. **Modal stack:** `useModalStack('crafting-panel', toggleCrafting)`.

  4. **Left Column — Discipline Tabs:**
     - 4 vertical buttons: Equipment, Consumables, Reagents, Automation
     - Each shows discipline name + proficiency level from `proficiency[discipline].level`
     - Active tab has highlighted style (e.g., `crafting-tab--active` class)
     - Below the tabs (or at top of middle column), show XP progress bar for active discipline
     - XP bar: calculate level thresholds using the formula from CraftingService: `level = floor(sqrt(xp / 100)) + 1`
       So for a given level L, xpForLevel = (L-1)^2 * 100. Current XP minus xpForCurrentLevel, divided by (xpForNextLevel - xpForCurrentLevel) gives progress percentage.
     - Apply CSS `transition: width 0.5s ease` on XP bar fill for smooth animation per user decision

  5. **Middle Column — Recipe List:**
     - Filter `recipes` by `activeDiscipline`: `recipes.filter(r => r.recipe.discipline === activeDiscipline)`
     - Each row: `<ItemIcon itemId={r.recipe.outputItemId} size={24} />` + recipe displayName + status indicator
     - Status indicator: if locked, show lock icon (GiLock or similar) in muted color; if craftable (unlocked + has ingredients), show green dot; if unlocked but missing ingredients, show orange dot
     - Locked recipes: add `crafting-recipe--locked` class for greyed-out appearance
     - Click handler: `setSelectedRecipeId(recipe.id)`
     - Selected recipe gets `crafting-recipe--selected` class
     - Scroll overflow if list is long: `overflow-y: auto`

  6. **Right Column — Detail Pane:**
     - If no recipe selected: show placeholder text "Select a recipe"
     - If recipe selected, show:
       a. **Header:** Output item icon (larger, 48px) + recipe displayName + recipe description
       b. **Ingredients section:** For each ingredient:
          - `<ItemIcon itemId={ing.itemId} size={20} />` + item display name
          - "xN/M" where N = owned count from inventory, M = required count
          - Use `crafting-ing--sufficient` (green) or `crafting-ing--insufficient` (red) class
          - Calculate owned: `inventory.items.filter(i => i.itemId === ing.itemId).reduce((s, i) => s + i.quantity, 0)`
       c. **Quality section:** Show quality tier probabilities as percentage badges
          - Call `getQualityThresholds(profLevel, recipe.tier)` where profLevel is `proficiency[recipe.discipline].level`
          - Display: `Standard: XX%  Refined: XX%  Masterwork: XX%`
          - Use colored badges: standard=grey, refined=blue, masterwork=gold/yellow
          - Only show non-zero tiers (at level 1, only standard shows)
       d. **Craft button or progress bar:**
          - If `activeCraft` is non-null: show progress bar
            - Progress: `Math.min(1, (Date.now() - activeCraft.startedAt) / activeCraft.durationMs)`
            - Use `useEffect` with a 100ms interval to update a local `progress` state
            - Display: progress bar fill + remaining seconds text
            - Clear interval on unmount or when activeCraft becomes null
          - If no active craft: show Craft button
            - Disabled if: recipe is locked OR not enough ingredients OR there's an active craft on any recipe
            - Disabled tooltip: explain why (locked reason, missing ingredients, or craft in progress)
            - On click: `startCraft(recipe.id)`

  7. **Locked recipe detail:** When a locked recipe is selected, the detail pane shows the recipe info but with a "Locked" overlay or banner and lists the `unlockReasons` array.
