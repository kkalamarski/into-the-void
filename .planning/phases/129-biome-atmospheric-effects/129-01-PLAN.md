**3. AtmosphereSystem class:**

Private state:
- `scene: Phaser.Scene`
- `currentBiome: BiomeType | null = null`
- `currentConfig: BiomeAtmosphereConfig | null = null`
- `outgoingConfig: BiomeAtmosphereConfig | null = null`
- `atmosphereAlpha: number = 1` (incoming config alpha)
- `outgoingAlpha: number = 0` (outgoing config alpha)
- `alphaProxy: { value: number } = { value: 1 }` (tween target)
- `transitionTween: Phaser.Tweens.Tween | null = null`

Public methods:

**`setBiome(biome: BiomeType, instant: boolean = false): void`**
- If `biome === this.currentBiome`, return early (no-op).
- Always cancel any in-progress tween first: `if (this.transitionTween) { this.transitionTween.destroy(); this.transitionTween = null; }` (rapid crossing support per CONTEXT.md).
- If `instant === true` (teleport):
  - Clear outgoing state (`outgoingConfig = null, outgoingAlpha = 0`).
  - Set `currentConfig` to new config, `atmosphereAlpha = 0`, `alphaProxy.value = 0`.
  - Create a tween from 0 to 1 over `TELEPORT_FADE_MS` (750ms) with `Sine.easeOut`.
  - `onUpdate`: set `atmosphereAlpha = alphaProxy.value`.
  - `onComplete`: null the tween reference.
- If `instant === false` (walk cross-fade):
  - Store `this.currentConfig` as `outgoingConfig`, capture `this.atmosphereAlpha` as `outgoingAlpha`.
  - Set `currentConfig` to new config, `atmosphereAlpha = 0`, `alphaProxy.value = 0`.
  - Create a tween from 0 to 1 over `CROSSFADE_MS` (3000ms) with `Sine.easeInOut`.
  - `onUpdate`: set `atmosphereAlpha = alphaProxy.value` and `outgoingAlpha = 1 - alphaProxy.value`.
  - `onComplete`: clear outgoing state (`outgoingConfig = null, outgoingAlpha = 0`), null tween ref.

**`applyToMatrix(colorMatrix: Phaser.FX.ColorMatrix, cycleProgress: number): void`**
- Called by DayNightCycle AFTER all day/night writes. DO NOT call reset() or any ColorMatrix named methods — only mutate getData() array directly.
- Get `const m = colorMatrix.getData()`.
- If `outgoingConfig && outgoingAlpha > 0`: call `writeAtmosphere(m, outgoingConfig, cycleProgress, outgoingAlpha)`.
- If `currentConfig && atmosphereAlpha > 0`: call `writeAtmosphere(m, currentConfig, cycleProgress, atmosphereAlpha)`.

**Private `writeAtmosphere(m: Float32Array, config: BiomeAtmosphereConfig, cycleProgress: number, alpha: number): void`**
- Get modulated params via `getModulatedParams(config, cycleProgress)`.
- Add channel offsets: `m[4] += params.rOffset * alpha`, `m[9] += params.gOffset * alpha`, `m[14] += params.bOffset * alpha`.
- If `params.brightnessBoost !== 0`: add to diagonal `m[0], m[6], m[12]` (all += `params.brightnessBoost * alpha`).

**Private `getModulatedParams(config: BiomeAtmosphereConfig, cycleProgress: number): AtmosphereParams`**
- Copy the `smoothStep()` function from DayNightCycle.ts (Hermite smoothstep, same implementation).
- Calculate day/night factors from `cycleProgress`:
  - `cycleProgress` maps: Dawn = 0.0-0.1, Day = 0.1-0.5, Dusk = 0.5-0.6, Night = 0.6-1.0 (from PHASE_BOUNDARIES).
  - `nightFactor`: Smooth 0→1 as progress moves into night territory (0.6-1.0). Use smoothStep to interpolate.
  - `dayFactor`: Smooth 0→1 as progress approaches mid-day (around 0.25-0.45).
  - `dawnDuskFactor`: 1.0 during dawn/dusk transitions, 0 otherwise.
- Switch on `config.effectType`:
  - **fog**: Thicker at night/dawn. Multiply r/g/bOffset by `(1 + nightFactor * 0.3)` for r,g and `(1 + nightFactor * 0.5)` for b. Reduce brightnessBoost by `nightFactor * 0.05`.
  - **glow**: Brighter at night. Multiply g/bOffset by `(1 + nightFactor * 0.4)`. Add `nightFactor * 0.1` to brightnessBoost. IMPORTANT: Cap brightnessBoost so GLOW only adds brightness at night, not during day. If `cycleProgress < 0.5` (day half), return `brightnessBoost = config.brightnessBoost` (no boost).
  - **haze**: Strongest at noon. Multiply rOffset by `(1 + dayFactor * 0.4)`, gOffset by `(1 + dayFactor * 0.2)`. Add `dayFactor * 0.05` to brightnessBoost.
  - **murk**: Darker at night. Subtract `nightFactor * 0.08` from brightnessBoost.
  - **shimmer**: Shifts hue at dusk/dawn. Multiply rOffset by `(1 + dawnDuskFactor * 0.3)`, reduce bOffset by `(1 - dawnDuskFactor * 0.2)`.
  - **clear**: Return config values unchanged.

**`destroy(): void`**
- Cancel tween if active (`this.transitionTween?.destroy()`).
- Null all references.

**CRITICAL CONSTRAINTS (from RESEARCH.md):**
- NEVER call `camera.postFX.clear()` — this destroys DayNightCycle's ColorMatrix.
- NEVER call `camera.postFX.addColorMatrix()` — the system receives the existing matrix via applyToMatrix().
- NEVER queue transitions — always cancel in-progress and start new one.
- getData() mutations are additive on top of DayNightCycle's writes. Values are in post-division scale (0.0-1.0 range).
