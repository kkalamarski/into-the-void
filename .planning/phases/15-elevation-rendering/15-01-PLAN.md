<task type="auto">
  <name>Task 1: Add createTileWithElevation to TileRenderer with side faces</name>
  <files>apps/web/src/game/rendering/TileRenderer.ts</files>
  <action>
Add constant at top of file:
```typescript
const ELEVATION_HEIGHT_STEP = 16; // Pixels per elevation level (5 levels = 80px max)
```

Add new method `createTileWithElevation` that:
1. Takes parameters: `x: number, y: number, tileId: TileId, elevation: number, heights: number[][]`
2. Gets screen position from isoTransform.gridToScreen(x, y)
3. Calculates elevationOffset = elevation * ELEVATION_HEIGHT_STEP
4. Creates a Phaser container at (screenPos.x, screenPos.y - elevationOffset)
5. Stores gridX, gridY, elevation in container data
6. Creates side faces FIRST (render behind top face):
   - Check south neighbor: if y < heights.length - 1 and heights[y+1][x] < elevation, create south face for (elevation - heights[y+1][x]) steps
   - Check east neighbor: if x < heights[0].length - 1 and heights[y][x+1] < elevation, create east face for (elevation - heights[y][x+1]) steps
7. Creates top face (existing diamond logic from createTile, but relative to container at 0,0)
8. Sets container depth using isoTransform.calculateDepth(x, y, elevation)
9. Returns the container

Add private method `createSouthFace(elevationSteps: number)`:
- Creates Graphics object
- Fills with dark color 0x1a1a2a (darker than any tile for shading)
- South face is rectangle from diamond bottom point extending right and down
- Diamond bottom is at (0, halfHeight) relative to container
- Rectangle: fillRect(0, halfHeight, halfWidth, elevationSteps * ELEVATION_HEIGHT_STEP)
- Returns graphics

Add private method `createEastFace(elevationSteps: number)`:
- Creates Graphics object
- Fills with even darker color 0x0a0a1a (two-tone shading effect)
- East face is parallelogram from diamond bottom extending left
- Uses beginPath/moveTo/lineTo/closePath/fillPath for parallelogram:
  - Start at (0, halfHeight) - diamond bottom center
  - Line to (-halfWidth, 0) - diamond left point
  - Line to (-halfWidth, elevationSteps * ELEVATION_HEIGHT_STEP) - left face top
  - Line to (0, halfHeight + elevationSteps * ELEVATION_HEIGHT_STEP) - right face top
  - closePath/fillPath
- Returns graphics

Modify existing `createTopFace` method (or create if not separate):
- Extract the diamond drawing logic from createTile
- Draw relative to (0, 0) instead of screenPos (for container-relative rendering)
- Return graphics object

Keep existing `createTile` method for backward compatibility (other code may use it).
