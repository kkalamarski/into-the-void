  <files>apps/web/src/game/systems/HoverController.ts</files>
  <action>
Create HoverController class that manages hover detection and visual feedback:

1. Constructor takes scene, isoTransform, and entitySprites map reference
2. Create two Graphics objects:
   - `highlightGraphics` for tile hover (depth 10000)
   - `clickMarkerGraphics` for click feedback (depth 10001, above path)

3. Implement `update()` method (called from scene update loop):
   - Get pointer via `scene.input.activePointer`
   - Convert to world coords: `camera.getWorldPoint(pointer.x, pointer.y)`
   - Convert to grid: `isoTransform.screenToTile(worldPoint.x, worldPoint.y)`
   - Only redraw if tile changed (store `lastHoveredTile` to compare)
   - If tile changed: call `drawTileHighlight(gridX, gridY)`
   - If pathfinding active (check via callback): skip tile highlight to avoid visual clutter
   - Check for entity at position: iterate entitySprites map, compare getData('gridX')/getData('gridY')
   - If entity found and different from `hoveredEntityId`: call `highlightEntity(id)` and `clearEntityHighlight()` on previous

4. Implement `drawTileHighlight(gridX, gridY)`:
   - Clear highlightGraphics
   - Calculate screen position via `isoTransform.gridToScreen()`
   - Draw isometric diamond outline (same pattern as PathfindingController):
     - hw = 64, hh = 32 (half tile dimensions)
     - lineStyle(2, 0xffffff, 0.6)
     - fillStyle(0xffffff, 0.1)
     - Diamond path: top -> right -> bottom -> left -> close
     - strokePath() and fillPath()

5. Implement `showClickMarker(gridX, gridY)`:
   - Create temporary Graphics (NOT reusing clickMarkerGraphics - create fresh each click)
   - Calculate screen position
   - fillStyle(0x00ff00, 0.8), fillCircle(screenX, screenY, 8)
   - setDepth(10001)
   - Add tween: alpha 0, scale 2, duration 300, ease 'Cubic.easeOut'
   - onComplete: marker.destroy()
   - Use scene.tweens.add() for the tween

6. Implement `highlightEntity(entityId)`:
   - Get container from entitySprites
   - Create overlay Graphics: fillStyle(0xffffff, 0.15), fillEllipse(0, -12, 50, 30)
   - Add overlay to container at index 2 (after shadow and sprite, before health bar)
   - Store overlay via container.setData('hoverOverlay', overlay)

7. Implement `clearEntityHighlight()`:
   - Get previous container via hoveredEntityId
   - Get overlay via container.getData('hoverOverlay')
   - If exists: overlay.destroy(), container.setData('hoverOverlay', null)

8. Implement `clearHighlights()`:
   - Clear highlightGraphics
   - Clear entity highlight
   - Reset lastHoveredTile and hoveredEntityId to null

9. Implement `destroy()`:
   - Clear all highlights
   - Destroy highlightGraphics
   - Scene tweens cleanup not needed (click markers self-destruct)

10. Add `setPathfindingActiveCallback(fn: () => boolean)` to check if pathfinding is active

Export the class for use in WorldScene.
