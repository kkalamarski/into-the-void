**Part B: Auto-targeting (fix "Ability requires a target")**

In `useAbility()`, when `ability.requiresTarget` is true but `targetEntityId` is undefined/null, instead of returning an error, auto-select the nearest valid entity:

```typescript
if (ability.requiresTarget) {
  if (!targetEntityId) {
    // Auto-target nearest valid entity
    const autoTarget = this.findNearestTarget(player, ability);
    if (!autoTarget) {
      return { success: false, error: 'No target' };
    }
    targetEntityId = autoTarget.id;
  }
  // ... rest of entity validation
}
```

Add a private method `findNearestTarget(player, ability)`:
1. Get all entities from 3x3 grid via `this.zonesService.getEntitiesAcrossZones(player.position.zoneId)`
2. Filter by type: if ability has gather effect, filter for `plant`/`mineral`/`artifact`; otherwise filter for `creature` with `active === true` and `health > 0`
3. For each candidate, compute pixel distance from player (player.px, player.py) to entity. Entity pixel position: `entity.position.x * TILE_SIZE_PX + TILE_SIZE_PX/2` and same for y (center of tile). Import TILE_SIZE_PX from game-logic.
4. Filter by range: for gather abilities use GATHER_RANGE_PX, for combat use `(ability.range + 0.5) * TILE_SIZE_PX`
5. Return nearest by pixel distance, or undefined if none in range
