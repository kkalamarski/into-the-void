**Internal state:**
```typescript
interface ActiveCraft {
  recipeId: string;
  startedAt: number;
  durationMs: number; // adjusted for proficiency
```

**Methods to implement:**

1. `async loadProficiency(characterId: string): Promise<CraftingProficiencyJson>` — Mirror GatheringService pattern. Load from DB, cache in Map, create default row if missing. Use `craftingProficiency` table with `DEFAULT_CRAFTING_PROFICIENCY`.

2. `unloadPlayer(characterId: string): void` — Cancel active craft if any (clearTimeout, delete from Map), evict proficiency cache. Called on player disconnect.

3. `async startCraft(socketId: string, recipeId: string): Promise<StartCraftResult>` where:
```typescript
type StartCraftResult =
  | { success: true; recipeId: string; durationMs: number; startedAt: number }
  | { success: false; code: string; message: string };
```

Validation order in startCraft:
  a. Get player from PlayerService.getPlayerBySocket(socketId) — error if not found
  b. Check `activeCrafts.has(characterId)` — if yes, return `{ code: 'CRAFT_ACTIVE', message: 'A craft is already in progress' }`
  c. Look up recipe by `recipeId` — for Phase 122, create a simple `RecipeRegistry` Map at module level (empty for now, recipes added in Phase 123). If recipe not found: `{ code: 'RECIPE_NOT_FOUND', message: 'Recipe does not exist' }`
  d. Check faction restriction: if `recipe.factionRestriction` is defined, get player's character from DB/PlayerService and compare factionId. If mismatch: `{ code: 'WRONG_FACTION', message: 'This recipe requires [faction] faction membership' }`
  e. Check unlock conditions: for each condition in `recipe.unlockConditions`:
     - `type: 'level'` — check `player.level >= condition.requiredLevel`
     - `type: 'quest'` — check `recipeUnlocks` table for matching (characterId, recipeId) entry
     - `type: 'poi'` — check `recipeUnlocks` table for matching entry
     If any unmet: `{ code: 'RECIPE_LOCKED', message: 'Recipe locked: [reason]' }`
  f. Call `inventoryService.consumeItems(characterId, recipe.ingredients)` — if fails, return `{ code: 'MISSING_INGREDIENTS', message: result.reason }`
  g. Calculate adjusted duration:
     ```typescript
     const prof = await this.loadProficiency(characterId);
     const disciplineData = prof[recipe.discipline];
     // Diminishing returns curve: speedMultiplier = 1 - 0.5 * (level / MAX_CRAFT_LEVEL)^0.7
     const MAX_CRAFT_LEVEL = 50; // reasonable cap
     const speedFactor = 1 - 0.5 * Math.pow(Math.min(disciplineData.level, MAX_CRAFT_LEVEL) / MAX_CRAFT_LEVEL, 0.7);
     const adjustedDuration = Math.round(recipe.craftTimeMs * speedFactor);
     ```
  h. Store active craft in Map with setTimeout that auto-completes:
     ```typescript
     const startedAt = Date.now();
     const timerId = setTimeout(() => {
       // Mark craft as ready for collection (set a readyAt timestamp)
       const craft = this.activeCrafts.get(characterId);
       if (craft) {
         // Craft timer elapsed — client can now collect
       }
     }, adjustedDuration);
     this.activeCrafts.set(characterId, { recipeId, startedAt, durationMs: adjustedDuration, timerId, characterId });
     ```
  i. Emit internal event: `this.eventEmitter.emit('craft.started', { characterId, recipeId })`
  j. Return `{ success: true, recipeId, durationMs: adjustedDuration, startedAt }`

4. `async collectCraft(socketId: string): Promise<CollectCraftResult>` where:
```typescript
type CollectCraftResult =
  | { success: true; recipeId: string; outputItemId: string; qualityTier: QualityTier; proficiencyXP: number; discipline: CraftingDiscipline }
  | { success: false; code: string; message: string };
```

Logic:
  a. Get player, check active craft exists — if not: `{ code: 'NO_ACTIVE_CRAFT', message: 'No craft in progress' }`
  b. Check timer: `if (Date.now() < craft.startedAt + craft.durationMs)` return `{ code: 'CRAFT_NOT_READY', message: 'Craft still in progress' }`
  c. Look up recipe, clear active craft (clearTimeout, delete from Map)
  d. Add output item to inventory via `inventoryService.addItem(characterId, { itemId: recipe.outputItemId, quantity: 1, ... })` — generate instanceId with `crypto.randomUUID()`, assign slot, properties: `{}`
  e. Award proficiency XP: update proficiency cache and DB (mirror GatheringService.awardProficiencyXP pattern). Use `calculateLevelFromXP` from game-logic if available, otherwise implement simple level formula.
  f. Quality tier: for Phase 122, always return `'standard'` (quality calculation deferred to Phase 123)
  g. Emit internal event: `this.eventEmitter.emit('craft.completed', { characterId, recipeId, outputItemId: recipe.outputItemId })`
  h. Return success result

5. `getActiveCraft(characterId: string): ActiveCraft | undefined` — for gateway to check state.

**Important design decisions (from CONTEXT.md):**
- Ingredients consumed on start, NOT refunded on disconnect (prevents exploit per STATE.md)
- Fire-and-forget: no manual cancel
- Crafting continues during combat — no combat check needed
- Always produce exactly 1 output item
- Proficiency speed bonus uses diminishing returns curve capped at 50%

3. Add `@SubscribeMessage('crafting:start')` handler:
```typescript
@SubscribeMessage('crafting:start')
async handleCraftingStart(
  @ConnectedSocket() client: Socket,
  @MessageBody() data: ClientEvents['crafting:start']
) {
  const result = await this.craftingService.startCraft(client.id, data.recipeId);
  if (!result.success) {
    client.emit('crafting:error', { code: result.code, message: result.message });
    return;
  }
  // Send to player
  client.emit('crafting:started', {
    recipeId: result.recipeId,
    durationMs: result.durationMs,
    startedAt: result.startedAt,
  });
  // Broadcast to nearby players in same zone
  const player = this.playerService.getPlayerBySocket(client.id);
  if (player) {
    client.to(player.position.zoneId).emit('crafting:nearby', {
      playerId: player.id,
      recipeId: result.recipeId,
    });
  }
}
```

4. Add `@SubscribeMessage('crafting:collect')` handler:
```typescript
@SubscribeMessage('crafting:collect')
async handleCraftingCollect(
  @ConnectedSocket() client: Socket,
) {
  const result = await this.craftingService.collectCraft(client.id);
  if (!result.success) {
    client.emit('crafting:error', { code: result.code, message: result.message });
    return;
  }
  // Send completion to player
  client.emit('crafting:completed', {
    recipeId: result.recipeId,
    outputItemId: result.outputItemId,
    qualityTier: result.qualityTier,
    proficiencyXP: result.proficiencyXP,
    discipline: result.discipline,
  });
  // Send updated inventory
  const player = this.playerService.getPlayerBySocket(client.id);
  if (player) {
    const inventory = this.inventoryService.getInventory(player.id);
    if (inventory) {
      client.emit('inventory:update', inventory);
    }
  }
}
```
