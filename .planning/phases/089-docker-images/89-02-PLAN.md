  <name>Task 1: Create nginx configuration for SPA</name>
  <files>apps/web/nginx.conf</files>
  <action>
Create apps/web/nginx.conf with:

```nginx
server {
    listen 80;
    server_name _;
    root /usr/share/nginx/html;
    index index.html;

    # Gzip compression
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml;
    gzip_min_length 1000;

    # Cache static assets aggressively (Vite adds hashes to filenames)
    location /assets/ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # SPA fallback - serve index.html for all routes
    location / {
        try_files $uri $uri/ /index.html;
    }

    # Health check endpoint
    location /health {
        access_log off;
        return 200 'ok';
        add_header Content-Type text/plain;
    }
}
```

Key points:
- SPA routing via try_files (React Router handles client-side routing)
- Long cache for /assets/ (Vite content-hashes these files)
- /health endpoint for container orchestration (returns 200 plain text)
- Gzip for smaller transfers

<task type="auto">
  <name>Task 2: Create web Dockerfile with multi-stage build</name>
  <files>apps/web/Dockerfile</files>
  <action>
Create apps/web/Dockerfile with multi-stage build:

Stage 1 (builder):
- FROM node:20-alpine AS builder
- WORKDIR /app
- Enable corepack: `corepack enable pnpm`
- Copy package.json, pnpm-lock.yaml, pnpm-workspace.yaml
- Copy nx.json, tsconfig.base.json
- Copy all workspace packages (apps/, packages/) - Vite needs path aliases
- Run `pnpm install --frozen-lockfile`
- ARG for build-time env vars:
  - VITE_API_URL (default empty, set at build time)
  - VITE_GAME_SERVER_URL (default empty, set at build time)
- Run `pnpm nx run web:build`

Stage 2 (runner):
- FROM nginx:alpine
- Copy built assets from builder /app/dist/apps/web to /usr/share/nginx/html
- Copy nginx.conf to /etc/nginx/conf.d/default.conf
- EXPOSE 80
- HEALTHCHECK CMD wget -q --spider http://localhost/health || exit 1
- CMD ["nginx", "-g", "daemon off;"]

Important: VITE_* env vars are baked into the build at compile time (not runtime).
Build with: `docker build --build-arg VITE_API_URL=https://api.example.com ...`
