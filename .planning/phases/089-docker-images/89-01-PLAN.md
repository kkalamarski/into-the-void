<task type="auto">
  <name>Task 3: Create API Dockerfile with multi-stage build</name>
  <files>apps/api/Dockerfile</files>
  <action>
Create apps/api/Dockerfile with multi-stage build:

Stage 1 (builder):
- FROM node:20-alpine AS builder
- WORKDIR /app
- Enable corepack for pnpm: `corepack enable pnpm`
- Copy package.json, pnpm-lock.yaml, pnpm-workspace.yaml
- Copy nx.json, tsconfig.base.json (needed for NX build)
- Copy all workspace packages (apps/, packages/) - NX needs full workspace
- Run `pnpm install --frozen-lockfile`
- Run `pnpm nx run api:build --prod`

Stage 2 (runner):
- FROM node:20-alpine
- WORKDIR /app
- Copy dist/apps/api from builder (includes generated package.json)
- Copy node_modules from builder (NX generates external deps in package.json)
- Install production deps only: `cd dist/apps/api && npm install --omit=dev`
- ENV NODE_ENV=production
- EXPOSE 3000
- HEALTHCHECK CMD wget -q --spider http://localhost:3000/api/health || exit 1
- CMD ["node", "main.js"]

Key: NX's generatePackageJson creates dist/apps/api/package.json with external dependencies.
  </action>
  <verify>`cat apps/api/Dockerfile | head -20`</verify>
  <done>Dockerfile exists with builder and runner stages, HEALTHCHECK directive present</done>
</task>
