Update the trader NPC inventories to include some of the new items. This makes new items obtainable through purchase, not just drops.

**Trader inventory format:**
```typescript
{ itemId: string, buyPrice: number, sellPrice: number, stock: number }
```

**Faction-appropriate item distribution:**

**Verdant Trader (verdant.ts)** - focuses on bio/organic items:
Add to VERDANT_TRADER inventory:
```typescript

{ itemId: 'antitoxin_rare', buyPrice: 300, sellPrice: 150, stock: 5 },
{ itemId: 'world_luminous_extract', buyPrice: 350, sellPrice: 175, stock: 6 },
{ itemId: 'reagent_bioluminescent_compound', buyPrice: 55, sellPrice: 28, stock: 15 },
```

**Helix Trader (helix.ts)** - focuses on industrial/mining items:
Add to HELIX_TRADER inventory:
```typescript
{ itemId: 'world_meteor_fragment', buyPrice: 3000, sellPrice: 1500, stock: 2 },
{ itemId: 'reagent_frost_essence', buyPrice: 220, sellPrice: 110, stock: 8 },
{ itemId: 'reagent_petrification_enzyme', buyPrice: 1400, sellPrice: 700, stock: 3 },
```

**Nexus Trader (nexus.ts)** - focuses on general trade goods:
Add to NEXUS_TRADER inventory:
```typescript
{ itemId: 'antitoxin_common', buyPrice: 75, sellPrice: 38, stock: 12 },
{ itemId: 'world_coastal_shell', buyPrice: 70, sellPrice: 35, stock: 20 },
{ itemId: 'world_spore_sack', buyPrice: 500, sellPrice: 250, stock: 4 },
{ itemId: 'reagent_bioluminescent_compound', buyPrice: 50, sellPrice: 25, stock: 20 },
```

**Pricing guidelines:**
- buyPrice is typically 2x sellPrice (50% trade margin)
- Common items: buyPrice 50-100
- Rare items: buyPrice 200-500
- Epic items: buyPrice 1000-2000
- Exotic items: buyPrice 2500-5000
- Stock scales inversely with rarity (common: 10-20, rare: 5-10, epic: 2-5, exotic: 1-3)
