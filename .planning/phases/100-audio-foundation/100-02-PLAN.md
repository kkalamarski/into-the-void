**A. GameContainer.tsx — First-gesture gate + visibilitychange listener**

Add `import { audioManager } from '../utils/audio';` at top (local relative imports section).

Add a new `useEffect` hook (after the existing Phaser initialization effect). This effect handles two concerns:

1. **First-gesture gate (AUD-02):** Attach one-time event listeners for `click` and `keydown` on `document` that call `audioManager.init()`. Use `{ once: true }` for automatic removal after first trigger. In the cleanup, remove both listeners (defensive — `once` should handle it but explicit cleanup is safer for HMR).

```typescript
useEffect(() => {
  const handleFirstGesture = async () => {
    await audioManager.init();
    // Remove both listeners (whichever fired first)
    document.removeEventListener('click', handleFirstGesture);
    document.removeEventListener('keydown', handleFirstGesture);
  };

  document.addEventListener('click', handleFirstGesture, { once: true });
  document.addEventListener('keydown', handleFirstGesture, { once: true });

  return () => {
    document.removeEventListener('click', handleFirstGesture);
    document.removeEventListener('keydown', handleFirstGesture);
  };
}, []);
```

2. **Tab visibility (user decision: music pauses on blur, resumes on focus):** Add a separate `useEffect` for `visibilitychange`:

```typescript
useEffect(() => {
  const handleVisibility = () => {
    audioManager.handleVisibilityChange(document.hidden);
  };

  document.addEventListener('visibilitychange', handleVisibility);
  return () => document.removeEventListener('visibilitychange', handleVisibility);
}, []);
```

If direct download URLs are not available or require authentication, generate the SFX files using `ffmpeg` to create simple synthetic sounds matching the required style.

**Required files and style guidance:**

1. **`sfx-combat-hit.mp3`** — Sci-fi combat impact. Short (~0.3-0.5s). Energy pulse / laser impact with weight. Not a soft beep — should feel like a hit landing. If generating with ffmpeg, use a noise burst with quick decay and a low-frequency thump.

2. **`sfx-ui-click.mp3`** — Subtle mechanical UI click. Very short (~0.1-0.2s). Clean, not loud or distracting. Mechanical/digital feel. If generating with ffmpeg, a short sine wave click at ~800Hz with fast decay.

3. **`sfx-gathering.mp3`** — Digital chime for resource collection. Short (~0.5-0.8s). Mineral extraction / digital acquisition sound. Ascending tone or crystalline chime. If generating with ffmpeg, a rising two-tone sine at ~600Hz -> ~900Hz with ~0.3s decay.

**Approach priority:**
1. First try to download from free asset sources (Pixabay audio, Freesound, etc.)
2. If downloads fail (auth required, etc.), use `ffmpeg` to synthesize:
   ```bash
   # Example combat hit (noise burst + thump)
   ffmpeg -f lavfi -i "anoisesrc=d=0.15:c=pink:a=0.8" -af "afade=t=out:st=0.05:d=0.1" -t 0.15 /tmp/hit.wav
   ffmpeg -f lavfi -i "sine=f=80:d=0.3" -af "afade=t=out:st=0.05:d=0.25,volume=0.6" -t 0.3 /tmp/thump.wav
   ffmpeg -i /tmp/hit.wav -i /tmp/thump.wav -filter_complex amix=inputs=2:duration=longest -b:a 128k output.mp3
   ```
3. Keep files small (under 50KB each for quick loading)
