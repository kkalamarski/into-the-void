  <files>apps/web/src/utils/audio.ts</files>
  <action>
Replace the entire contents of `apps/web/src/utils/audio.ts` with an `AudioManager` class. The old `playQuestCompleteSound()` function is removed (callers will be updated in Plan 02).

**AudioManager class requirements:**

1. **Private fields:**
   - `ctx: AudioContext | null` — created lazily on `init()`
   - `masterGain, musicGain, effectsGain, ambientGain: GainNode | null`
   - `musicSource: AudioBufferSourceNode | null`
   - `musicBuffer: AudioBuffer | null`
   - `musicStarted: boolean` — prevents restart on WorldScene re-init
   - `sfxCache: Map<string, AudioBuffer>` — decoded buffer cache for SFX performance
   - `initialized: boolean` — prevents double-init

2. **`async init(): Promise<void>`** — Called on first user gesture.
   - Guard: `if (this.initialized) return;`
   - Create `AudioContext` SYNCHRONOUSLY (before any await) — critical for Safari gesture association.
   - Set `this.initialized = true` immediately after creating AudioContext.
   - Build gain chain: `musicGain -> masterGain -> ctx.destination`, same for `effectsGain` and `ambientGain`.
   - Call `this.syncVolumesFromStore()` at the end to apply persisted values.

3. **`async ensureRunning(): Promise<void>`** — Call `ctx.resume()` if state is `'suspended'`. Guard with `if (!this.ctx) return`.

4. **`async startMusic(src: string): Promise<void>`** — Gapless looped playback.
   - Guard: `if (!this.ctx || this.musicStarted) return;` — prevents restart on zone transition.
   - Call `ensureRunning()`.
   - `fetch(src)` -> `arrayBuffer()` -> `ctx.decodeAudioData()`.
   - Store decoded buffer in `this.musicBuffer`.
   - Create `AudioBufferSourceNode`, set `loop = true`, connect to `musicGain`, call `start()`.
   - Set `this.musicStarted = true`.

5. **`async playEffect(src: string): Promise<void>`** — Fire-and-forget SFX with buffer caching.
   - Guard: `if (!this.ctx || !this.effectsGain) return;`
   - Call `ensureRunning()`.
   - Check `this.sfxCache.get(src)`. If miss: fetch -> decode -> cache in map.
   - Create new `AudioBufferSourceNode` from cached buffer, connect to `effectsGain`, `start()`.
   - Each call creates a NEW source node (overlap supported natively, no restart).

6. **Volume setters** — `setMasterVolume(v)`, `setMusicVolume(v)`, `setEffectsVolume(v)`, `setAmbientVolume(v)`.
   - Each: `if (this.{gain}) this.{gain}.gain.value = v;`
   - Null-safe — may be called before init (Zustand persist hydrates before first gesture).

7. **`handleVisibilityChange(hidden: boolean): void`** — Tab focus/blur.
   - `if (!this.ctx) return;`
   - `hidden ? this.ctx.suspend() : this.ctx.resume();`

8. **`private syncVolumesFromStore(): void`** — Reads current values from `useAudioStore.getState()` and applies to gain nodes.
   - Import `useAudioStore` with a lazy import pattern to break circular dependency:
     ```typescript
     private syncVolumesFromStore(): void {
       // Lazy import to avoid circular dependency (audioStore imports audioManager)
       const { useAudioStore } = require('../store/audioStore');
       const { master, music, effects, ambient } = useAudioStore.getState();
       this.setMasterVolume(master);
       this.setMusicVolume(music);
       this.setEffectsVolume(effects);
       this.setAmbientVolume(ambient);
     }
     ```
     Alternatively, use dynamic `import()` if require is not available in the Vite context — choose what works. The key is: do NOT put `import { useAudioStore } from '../store/audioStore'` at the top of the file because audioStore imports audioManager, creating a circular dependency.

9. **Export:** `export const audioManager = new AudioManager();` — singleton instance at module level. AudioContext is NOT created at module load time (only in `init()`).

**Anti-patterns to avoid:**
- Do NOT create `AudioContext` at module load time — will throw `NotAllowedError`.
- Do NOT use `<audio>` element for music — has audible gap at loop point.
- Do NOT store `AudioContext` or `GainNode` in Zustand — non-serializable.
- Do NOT call `source.start()` twice on the same `AudioBufferSourceNode` — `InvalidStateError`.
- Do NOT fetch+decode SFX on every play — use the `sfxCache` map.

Create `apps/web/src/store/audioStore.ts` following the same pattern as `authStore.ts` (Zustand `persist` middleware).

**Store interface:**
```typescript
interface AudioState {
  master: number;   // 0.0 - 1.0
  music: number;    // 0.0 - 1.0
  effects: number;  // 0.0 - 1.0
  ambient: number;  // 0.0 - 1.0
  setMaster: (v: number) => void;
  setMusic: (v: number) => void;
  setEffects: (v: number) => void;
  setAmbient: (v: number) => void;
}
```

**Implementation:**
```typescript
import { create } from 'zustand';
import { persist } from 'zustand/middleware';
import { audioManager } from '../utils/audio';
```

1. Use `create<AudioState>()(persist(...))` — same double-invocation as authStore.
2. Default values per user decision:
   - `master: 1.0` (100% — master scales others proportionally)
   - `music: 0.3` (30%)
   - `effects: 0.7` (70%)
   - `ambient: 0.5` (50%)
3. Each setter: (a) calls `set({ key: v })` to update state, (b) calls `audioManager.set{Category}Volume(v)` immediately.
   - `setMaster: (v) => { set({ master: v }); audioManager.setMasterVolume(v); }`
   - Same pattern for music, effects, ambient.
4. `persist` config:
   - `name: 'audio-settings'` (localStorage key)
   - `partialize: (state) => ({ master, music, effects, ambient })` — only persist numeric values, not setter functions.
5. Export: `export const useAudioStore = create<AudioState>()(persist(...));`

**Import direction:** audioStore imports `audioManager` from `../utils/audio`. This is the safe direction. The reverse direction (audio.ts importing audioStore) uses a lazy import in `syncVolumesFromStore()` to avoid circular dependency.

**Anti-patterns to avoid:**
- Do NOT store AudioContext or GainNode references in this store — non-serializable.
- Do NOT use immer middleware here — simple flat state, persist alone suffices.
