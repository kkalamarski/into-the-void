# Plan 135-01: Client-side legacy movement removal

## Objective

Delete `MovementController.ts` and `PathfindingController.ts`, then cascade-remove all imports, references, and dead code from WorldScene, gameStore, GameUI, GameContainer, entityStore, and socket.ts. After this plan, clicking the game world does nothing and WASD pixel movement is the only movement system on the client.

## Context

@apps/web/src/game/systems/MovementController.ts
@apps/web/src/game/systems/PathfindingController.ts
@apps/web/src/game/scenes/WorldScene.ts
@apps/web/src/store/gameStore.ts
@apps/web/src/ui/GameUI.tsx
@apps/web/src/components/GameContainer.tsx
@apps/web/src/store/entityStore.ts
@apps/web/src/network/socket.ts

## must_haves

- MovementController.ts and PathfindingController.ts are deleted from the filesystem
- No import or reference to MovementController or PathfindingController exists anywhere in apps/web/
- Clicking on the game world does nothing (no pathfinding, no console logs, no movement)
- WASD pixel movement via PixelMovementController continues to work unaffected
- The `player:moved` socket event listener is removed from gameStore.ts (replaced by positionBatch/positionCorrection)
- WorldScene compiles with no TypeScript errors after removal
