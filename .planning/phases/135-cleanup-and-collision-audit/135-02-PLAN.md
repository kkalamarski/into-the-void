# Plan 135-02: Server-side legacy removal, shared-types cleanup, and collision audit

## Objective

Remove the server-side tile-step `player:move` handler and its supporting code in game.service.ts, clean up shared-types event contracts, remove unused pathfinding/speed functions from game-logic, remove dead code from world-gen terrain.ts, and verify collision flags are correct across all biomes. After this plan, no tile-step movement code remains in the codebase (except creature AI wandering which intentionally stays tile-based).

@packages/game-logic/src/index.ts
@packages/world-gen/src/generation/terrain.ts

## must_haves

- Server `player:move` handler is removed from game.gateway.ts
- `movePlayer()` and `getMovementDelay()` methods removed from game.service.ts
- `player:move` and `player:moved` events removed from shared-types event contracts
- Unused pathfinding functions removed from game-logic (keeping only what creature-ai needs)
- Dead `isFeatureBlocking()` function removed from terrain.ts
- `MOVE_DELAY_MS` removed from constants.ts if unused
- No invisible walls exist from flat decorative tiles having blocking collision flags
- TypeScript build passes for all packages (api, game-server, web, shared-types, game-logic, world-gen)
- Cast interrupt on movement is NOT broken — verify pixel move path handles it
