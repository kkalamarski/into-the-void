**Verification steps:**

1. Start the development servers:
   ```bash
   pnpm dev
   ```

2. Open browser to http://localhost:5173

3. Log in and select a character to enter the game world

4. **Verify HUD (top-left corner):**
   - Health bar displays with red fill and current/max values
   - Energy bar displays with cyan/blue fill below health bar
   - XP bar displays below energy bar
   - Zone name with tier indicator visible (ZoneHUD from Phase 5)

5. **Verify Minimap (bottom-right corner):**
   - Minimap renders showing world tiles at zoomed-out scale
   - Player indicator (white dot with yellow border) visible at center
   - Biome colors visible in minimap matching world tiles
   - Border around minimap for visual distinction

6. **Verify Entity Rendering:**
   - If any entities exist in zone, they appear as colored tiles:
     - Creatures: red circles
     - Minerals: cyan squares
     - Items: yellow small circles
   - If entity is damaged (health < maxHealth), health bar appears above it
   - If entity is a creature, behavior icon (H/O/P/M letter) appears above health bar

7. **Verify Other Players (if multiplayer testing possible):**
   - When another player joins zone, they appear as a colored circle (faction tint)
   - When another player moves, their sprite moves smoothly
   - When another player leaves, their sprite disappears

8. **Window Resize Test:**
   - Resize browser window
   - Minimap repositions correctly to stay in bottom-right corner
   - HUD elements remain in correct positions

**Note:** Entity spawning depends on server sending entities in zone:state. If no entities appear, verify server is populating the entities array. This is expected behavior if server doesn't spawn entities yet.
