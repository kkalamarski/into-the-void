<task type="auto">
  <name>Task 1: Create EntityRenderer class with health bars and behavior icons</name>
  <files>apps/web/src/game/rendering/EntityRenderer.ts</files>
  <action>
Create EntityRenderer class that:

1. Constructor takes Phaser.Scene and TILE_SIZE (32)

2. createEntityContainer(entity: Entity) method:
   - Creates Phaser.GameObjects.Container positioned at entity.position
   - Adds sprite at (0, 0) using getEntityTexture() based on entity.type
   - If entity is Creature type AND health < maxHealth, add health bar at y = -20
   - If entity is Creature type, add behavior icon at y = -30 (above health bar)
   - Return container

3. createHealthBar(currentHealth: number, maxHealth: number) method:
   - Create Graphics object with width=30, height=4
   - Draw gray background (#333333)
   - Draw health fill colored by percentage:
     - >50% = green (#44cc44)
     - 25-50% = yellow (#ffcc00)
     - <25% = red (#ff4444)
   - Center horizontally (x = -15 to +15)
   - Return Graphics

4. createBehaviorIcon(behavior: CreatureBehavior) method:
   - Map behavior to icon letter per lore:
     - 'passive' -> 'H' (Herbivore - green #44cc44)
     - 'neutral' -> 'O' (Omnivore - yellow #ffcc00)
     - 'aggressive' -> 'P' (Predator - orange #ff6b35)
     - 'defensive' -> 'M' (Maniac - red #ff4444)
   - Create Text with letter, backgroundColor #000000, padding {x:4, y:2}
   - Set origin to center (0.5, 0.5)
   - Return Text

5. getEntityTexture(type: EntityType) helper:
   - creature -> 'creature'
   - mineral -> 'mineral'
   - item -> 'item'
   - default -> 'item'

6. isCreature(entity: Entity): entity is Creature type guard

Import Entity, Creature, CreatureBehavior, EntityType from @into-the-void/shared-types.
  </action>
