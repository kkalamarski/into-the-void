2. Add private method `checkPendingZoneTransition(position: Position)`:
   ```typescript
   private checkPendingZoneTransition(position: Position): void {
     if (!this.pendingZoneId) return;

     // Player returned to committed zone - cancel pending
     if (position.zoneId === this.currentZoneId) {
       this.pendingZoneId = null;
       this.pendingBiome = null;
       return;
     }

     // Player still in pending zone - check depth
     if (position.zoneId === this.pendingZoneId) {
       const depth = this.getZoneBoundaryDepth(position);
       if (depth >= HYSTERESIS_TILES) {
         this.commitZoneTransition(this.pendingZoneId, this.pendingBiome!);
         this.pendingZoneId = null;
         this.pendingBiome = null;
       }
     }
   }
   ```

3. Modify `onPlayerZoneChanged(newZoneId, biome)` (lines 553-583):

   - If no position, fall back to immediate commit (defensive)
   - Calculate depth: `const depth = this.getZoneBoundaryDepth(position);`
   - ALWAYS call `chunkManager.updateChunks(newZoneId)` immediately (keeps 3x3 pre-loading working)
   - If `depth >= HYSTERESIS_TILES`: call `commitZoneTransition(newZoneId, biome)`
