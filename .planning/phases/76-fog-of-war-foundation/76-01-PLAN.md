2. `setRevealed(worldX, worldY)` - set bit for tile using coordinate hash
3. `isRevealed(worldX, worldY)` - check if tile bit is set
4. `save(characterId)` - encode Uint8Array to base64, save to localStorage key `fog-revealed-${characterId}`
5. `load(characterId)` - load from localStorage, decode base64 to Uint8Array
6. `getRevealedCount()` - count set bits for debugging
7. `getAllRevealedTiles()` - return Set<string> of all revealed tile keys ("worldX,worldY")
   - Iterate through bitset, for each set bit, reverse the coordinate hash to get worldX, worldY
   - Reverse hash: `worldY = index % RANGE - OFFSET; worldX = Math.floor(index / RANGE) - OFFSET`

Coordinate hashing for negative coords:
- Use formula: `(worldX + OFFSET) * RANGE + (worldY + OFFSET)` where OFFSET=100000, RANGE=200000
- This maps coords from (-100000,-100000) to (99999,99999) into positive 1D index

Base64 encoding:
- Use native Uint8Array.toBase64() for save (ES2026)
- Use Uint8Array.fromBase64() for load
- Fallback to btoa/atob if native methods unavailable (older browsers)

Error handling:
- Wrap localStorage.setItem in try/catch for QuotaExceededError
- Log warning on quota exceeded, continue without persistence
- Return false from save() on error, true on success

Reveal radius algorithm (iterative BFS from research):
```typescript
const queue = [{x: centerX, y: centerY, dist: 0}];
const visited = new Set<string>();
const newlyRevealed = new Set<string>();

while (queue.length > 0) {
  const {x, y, dist} = queue.shift()!;
  const key = `${x},${y}`;

  if (visited.has(key) || dist > radius) continue;
  visited.add(key);

  if (!this.persistence.isRevealed(x, y)) {
    this.persistence.setRevealed(x, y);
    newlyRevealed.add(key);
  }

  // 4-directional spread
  for (const [dx, dy] of [[1,0], [-1,0], [0,1], [0,-1]]) {
    const nx = x + dx, ny = y + dy;
    if (!visited.has(`${nx},${ny}`)) {
      queue.push({x: nx, y: ny, dist: dist + 1});
    }
  }
}
return newlyRevealed;
```
