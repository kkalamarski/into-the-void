  <name>Task 1: Create FogRenderer with RenderTexture overlay</name>
  <files>apps/web/src/game/fog/FogRenderer.ts</files>
  <action>
Create FogRenderer class using Phaser RenderTexture for fog overlay:

1. Constructor takes Phaser.Scene and IsometricTransform
2. `create()` - initialize fog rendering:
   - Create RenderTexture sized to camera viewport (not full world)
   - Fill with dark overlay (0x000000, 0.6 alpha)
   - Set blend mode to MULTIPLY for darkening effect
   - Set depth to 1000 (above terrain at ~100-200, below UI at 2000)
   - Create Graphics object for drawing erase shapes
   - Position RenderTexture to follow camera (scrollFactor 1,1)

3. `revealTiles(tiles: Set<string>)` - batch reveal multiple tiles:
   - For each tile key ("worldX,worldY"), convert to screen coords
   - Draw white filled circle at screen position (radius = half tile width)
   - Use single Graphics object for batch drawing
   - Call `fogTexture.erase(graphics)` once after all circles drawn
   - This batches all erases into single WebGL draw call for performance

4. `revealTile(worldX, worldY)` - reveal single tile:
   - Convert world coords to screen coords via isoTransform.gridToScreen()
   - Account for camera scroll: screenX = worldScreenX - camera.scrollX
   - Draw white circle and erase from RenderTexture

5. `redrawFromState(fogManager: FogManager)` - rebuild fog from saved state:
   - Clear RenderTexture and refill with dark overlay
   - Get all revealed tiles via fogManager.getAllRevealedTiles()
   - Batch reveal all previously explored tiles
   - Called on game load to restore fog state

6. `updatePosition(camera)` - sync fog position with camera:
   - Set RenderTexture position to match camera scroll
   - Only update if camera moved (optimization)

7. `destroy()` - cleanup RenderTexture and Graphics objects

Performance considerations:
- RenderTexture sized to viewport (not world) saves memory
- Batch all reveals into single Graphics draw before erase()
- Only redraw fog when camera scrolls to new chunk boundary
- Use 60% opacity for fog (not 100%) so terrain is dimly visible
