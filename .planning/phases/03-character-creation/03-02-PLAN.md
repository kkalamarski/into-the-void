Create CharacterCreateScreen.tsx following React Router v7 action pattern:

**Exports:**
1. `action` function - Handles form submission via POST /characters
2. `default` - React component for the form UI

**Action Function:**
```typescript
export async function action({ request }: { request: Request }) {
  const formData = await request.formData();
  const name = formData.get('name') as string;
  const faction = formData.get('faction') as string;

  try {
    await apiCall('/characters', {
      method: 'POST',
      body: JSON.stringify({ name, faction }),
    });
    // Redirect triggers loader revalidation on character-select
    return redirect('/character-select');
  } catch (error) {
    return {
      error: error instanceof Error ? error.message : 'Failed to create character',
    };
  }
}
```

**Component Structure:**
- Uses `useActionData()` hook to get action return value (error object)
- Uses `useNavigation()` hook for submitting state (`navigation.state === 'submitting'`)
- Uses `Form` component from react-router (not native form)

**Form Fields:**

   - pattern="^[a-zA-Z0-9_]{3,20}$" (matches backend CreateCharacterDto validation)

   - title="3-20 characters (letters, numbers, underscores only)"
   - required, disabled={isSubmitting}
   - className="form-input"
   - Add `.form-hint` below: "3-20 characters (letters, numbers, underscores)"
