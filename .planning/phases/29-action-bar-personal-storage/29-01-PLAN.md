  <name>Task 1: Create actionBarStore with localStorage persistence and orphan invalidation</name>
  <files>apps/web/src/store/actionBarStore.ts</files>
  <action>
Create `actionBarStore.ts` as a separate Zustand store (NOT in gameStore or inventoryStore) with immer middleware.

Store structure:
- `slots: (string | null)[]` — length always 8, stores instanceId references
- `assign(slotIndex: number, instanceId: string)` — sets slot and persists to localStorage
- `unassign(slotIndex: number)` — clears slot and persists
- `invalidateOrphans(activeInstanceIds: Set<string>)` — clears any slot whose instanceId is not in the set

localStorage key: `'action_bar_assignments'`

Load from localStorage on store creation (parse JSON, normalize to 8 slots, handle errors gracefully).
Save to localStorage on every assign/unassign/invalidateOrphans that changes state.

CRITICAL: Wire orphan invalidation via `useInventoryStore.subscribe` at MODULE LEVEL (after store definition, not inside a component). This ensures stale references are cleared on every `inventory:update` regardless of component mount state.

```typescript
// At module level after store creation:
useInventoryStore.subscribe((inventoryState) => {
  const inv = inventoryState.inventory;
  if (!inv) return;
  const activeIds = new Set(inv.items.map((item) => item.instanceId));
  useActionBarStore.getState().invalidateOrphans(activeIds);
});
```

  <name>Task 2: Create ActionBar component with document keydown listener</name>
  <files>apps/web/src/ui/hud/ActionBar.tsx, apps/web/src/ui/hud/ActionBar.css</files>
  <action>
Create `ActionBar.tsx` component:

1. Read `slots` from `useActionBarStore()` and `inventory` from `useInventoryStore()`
2. Register `document.addEventListener('keydown', handler)` in a `useEffect` with cleanup
3. Keydown handler:
   - Check chat-focus guard: `if (document.activeElement?.tagName === 'INPUT' || document.activeElement?.tagName === 'TEXTAREA') return;`
   - Parse key: `const slotIndex = parseInt(e.key, 10) - 1;` (key '1' = index 0)
   - Ignore if slotIndex < 0 or > 7
   - Ignore if `e.repeat` (prevent held-key spam)
   - Get instanceId from `slots[slotIndex]`; if null, return
   - Verify item still in inventory: `inventory?.items.find(i => i.instanceId === instanceId)`; if not found, return
   - Emit: `gameSocket.emit('inventory:use', { instanceId })`

4. Render 8 slots as a horizontal bar:
   - Each slot shows key label (1-8) in corner
   - Filled slots show item icon (colored div with rarity border) wrapped in ItemTooltip
   - Empty slots show greyed placeholder
   - Orphaned slots (instanceId set but item not in inventory) show as empty/greyed

5. Make each slot a droppable target using `useDroppable` from `@dnd-kit/core` with `id: hotbar-{index}`

CSS (ActionBar.css):
- `.hotbar` — horizontal flex, centered at bottom of HUD area
- `.hotbar-slot` — 48x48px, border, rounded corners
- `.hotbar-slot--empty` — dimmed background
- `.hotbar-slot--filled` — item icon fills slot
- `.hotbar-key` — small label in top-left corner showing 1-8
- Use existing CSS variables: `--color-bg-secondary`, `--color-border`, etc.
