Update all 48 tool definitions with stats effects based on toolType:

**Tool Type to Primary Stat Mapping:**
- universal: power (general purpose, slight combat bonus)
- combat: power (offensive capability)
- mining: perception (resource detection, vein quality)
- research: perception (specimen analysis, data gathering)
- bio: vigor (biological interaction, specimen handling)
- demolition: power (structural damage)
- stealth: perception + haste (awareness and quick movement)
- anomaly: resilience (anomaly resistance)

**Stat Formula for Tools:**
Tools provide smaller bonuses than suits (roughly 20% of suit budget).
Base stat = 15 for tier 1 common.
Final stat = base * STAT_RARITY_MULTIPLIERS[rarity] * TIER_MULTIPLIERS[tier]

**Implementation:**
1. Import STAT_RARITY_MULTIPLIERS and TIER_MULTIPLIERS from utils.ts (from Plan 01)
2. Add helper function at top of file:
   ```typescript
   function getToolStats(toolType: ToolType, rarity: ItemRarity, tier: 1|2|3|4|5): { type: 'stats', [key: string]: number } {
     const base = 15;
     const rarityMult = STAT_RARITY_MULTIPLIERS[rarity];
     const tierMult = TIER_MULTIPLIERS[tier];
     const value = Math.round(base * rarityMult * tierMult);

     switch (toolType) {
       case 'combat':
       case 'demolition':
       case 'universal':
         return { type: 'stats', power: value };
       case 'mining':
       case 'research':
         return { type: 'stats', perception: value };
       case 'bio':
         return { type: 'stats', vigor: value };
       case 'stealth':
         return { type: 'stats', perception: Math.round(value * 0.6), haste: Math.round(value * 0.4) };
       case 'anomaly':
         return { type: 'stats', resilience: value };
       default:
         return { type: 'stats', power: value };
     }
   }
   ```

3. For each tool, update effects array:
   ```typescript
   effects: [
     { trigger: 'on_equip', effect: getToolStats(toolType, rarity, tier) },
   ],
   ```

4. Derive tier from requiredLevel:
   - 1-10 = tier 1
   - 11-20 = tier 2
   - 21-30 = tier 3
   - 31-40 = tier 4
   - 41-50 = tier 5

5. Keep existing grantedAbilities and range properties unchanged.

**Expected stat values (examples):**
