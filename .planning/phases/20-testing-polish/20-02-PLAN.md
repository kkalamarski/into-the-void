  <how-to-verify>
**Open browser to http://localhost:5173 and execute these test scenarios:**

### Scenario 1: Basic Chunk Boundary Crossing
1. Login and enter the game world
2. Move player towards a chunk boundary (edge of starting zone)
3. Cross into adjacent chunk
4. Verify: Loading indicator appears briefly (above minimap, not overlapping), chunk tiles appear seamlessly

### Scenario 2: Rapid Boundary Stress Test
1. Find a chunk boundary
2. Rapidly move back and forth across the boundary (WASD spam)
3. Do this for ~30 seconds
4. Verify: No visual artifacts, no console errors, no frozen states

### Scenario 3: Long-Distance Pathfinding
1. Click on a destination 2+ chunks away (64+ tiles)
2. Observe player following path across chunk boundaries
3. Verify: Path continues correctly across zones, pathfinding visualization clears when done

### Scenario 4: Entity Visibility Across Chunks
1. Move near a chunk boundary where entities exist in adjacent chunk
2. Verify: Entities in adjacent chunk visible within 48-tile radius
3. Check spawn timing: entities appear correctly when chunk loads

### Scenario 5: Disconnection/Reconnection
1. Open browser DevTools Network tab
2. Set to Offline mode briefly while moving (simulate disconnect)
3. Re-enable network
4. Verify: Connection recovers, chunk loading resumes correctly

### Scenario 6: Memory Profiling (30+ Chunk Transitions)
1. Open Chrome DevTools Memory tab
2. Take baseline heap snapshot
3. Move across 10 chunk boundaries, take snapshot
4. Continue to 30+ boundaries, take snapshot
5. Return to starting area, take snapshot
6. Verify: Memory returns to near-baseline, no accumulating Phaser.GameObjects.Graphics

**Report findings:**
- Pass/fail for each scenario
- Any console errors observed
- Memory snapshot comparison (before/after)
- Any visual issues noticed

Type "all tests passed" if everything works, or describe issues found.
