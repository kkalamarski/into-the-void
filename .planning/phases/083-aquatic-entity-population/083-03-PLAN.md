Add plant spawn logic in generateSpawnPoints() AFTER mineral spawning, following the same pattern:

- Set respawnTime from plant definition (or 300 + random 0-300 for ~5-10 min)

Add artifact spawn logic in generateSpawnPoints() AFTER plant spawning:

- Set respawnTime to -1 or omit (artifacts don't respawn - handled by ZonesService)
- EntityType: 'artifact'
