# Plan 112-01: Faction Suit Definitions

Create `packages/items/src/definitions/faction-suits.ts` with all 28 faction suit definitions (7 per faction: 5 main ladder + 2 off-archetype) using `generateSuitStats()` for all stat generation.

## Must-Haves (goal-backward)

1. 28 `ItemDefinition` exports: 7 Verdant, 7 Helix, 7 Nexus, 7 Unaffiliated
2. Every suit uses `generateSuitStats(archetype, rarity, tier)` -- zero hand-coded stat numbers
3. Every suit uses `computeIlvl(tier, rarity)` for ilvl
4. Archetype-to-tier mapping matches FACTION-IDENTITY.md Tier Progression Table exactly
5. Ability lists match FACTION-IDENTITY.md Suit Ability Progression table exactly (main ladder)
6. Off-archetype abilities are drawn from the correct off-archetype pool and differ from main ladder
7. Color values match the research document's color table per faction/rarity
8. textureKey values are unique per suit (no collisions with existing 16+ keys)
9. `ALL_FACTION_SUITS` array exported containing all 28 definitions
10. No ID collisions with existing items (especially `SUIT_NEXUS_COMBAT_FRAME_EXOTIC` and `SUIT_HELIX_RESEARCH_FRAME_EXOTIC`)

- **Pattern reference:** `packages/items/src/definitions/aquatic-suits.ts` and `exotic-suits.ts`
- **Design reference:** `packages/items/FACTION-IDENTITY.md` (Section 1-4, Section 6)
