# Plan 85-01: Gather Ability Types and Definitions

## Objective

Add gather effect type to the ability system and create Harvest/Mine abilities granted by tools.

## Tasks

### Task 1: Add GatherEffect to shared-types

**File**: `packages/shared-types/src/game/ability.ts`

Add new effect type:

```typescript
export interface GatherEffect {
  type: 'gather';
  gatherType: 'harvest' | 'mine';
  baseYield: number;
}
```

Update AbilityEffect union to include GatherEffect.

**File**: `packages/game-logic/src/ability/definitions.ts`

Add after utility abilities section:

