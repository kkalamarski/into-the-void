# Plan 85-03: Entity Collision Fix on Client

## Objective

Fix entity collision detection so minerals and plants block player movement while items, NPCs, and moving creatures do not.

## Background

The current collision detection in `isTileBlocked` (WorldScene.ts:2089-2091) checks if ANY entity is at a position. This has issues:
1. Items on the ground shouldn't block movement
2. NPCs shouldn't block movement (they're interactable, not obstacles)
3. Creatures that can move should allow player to path around them
4. Only static gatherable entities (minerals, plants) should block

## Tasks

### Task 1: Add blocking entity type check

**File**: `apps/web/src/game/scenes/WorldScene.ts`

In `isTileBlocked` method, change entity check to only block for static entities:

```typescript
// 2. Entity blocking - only static gatherable entities block
const entityAtTile = useEntityStore.getState().getEntityAtPosition(localX, localY, zoneId);
if (entityAtTile) {
  // Only minerals and plants block movement
  const blocksMovement = entityAtTile.type === 'mineral' || entityAtTile.type === 'plant';
  if (blocksMovement) return true;
}
```
