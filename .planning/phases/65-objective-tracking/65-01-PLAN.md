  <name>Task 2: Create QuestService with @OnEvent listeners</name>
  <files>

  <action>
    1. Create apps/game-server/src/game/quest.service.ts:
       - @Injectable() decorator
       - Constructor: inject DatabaseService and PlayerService
       - private server: Server | null field
       - setServer(server: Server): void method (called from GameGateway.afterInit)

    2. Implement @OnEvent('entity.killed') handler:
       - Payload: { characterId: string; entityId: string; entityType: string; creatureLevel: number; zoneId: string }
       - Wrap body in try/catch (log errors, don't rethrow)
       - Call getActiveQuests(db, characterId)
       - For each active quest, get definition from QuestRegistry
       - Map objectives: if objectiveType === 'kill' && targetId === entityId && !complete, increment current
       - Use Math.min(current + 1, required) to prevent exceeding target
       - Set complete = true when current >= required
       - If any objective changed: await updateQuestObjectives(db, id, updatedObjectives)
       - Then emit quest:progress to player socket

    3. Implement @OnEvent('item.collected') handler:
       - Payload: { characterId: string; itemId: string; quantity: number }
       - Same pattern as kill, but for objectiveType === 'gather'
       - Add quantity (not just 1): Math.min(current + quantity, required)

    4. Implement @OnEvent('zone.entered') handler:
       - Payload: { characterId: string; zoneId: string; biome: string }
       - For objectiveType === 'explore' where targetId === biome
       - Set current = 1 and complete = true (binary: explored or not)

    5. Private emitProgressUpdate method:
       - Get socketId via playerService.getSocketByPlayerId(characterId)
       - If no socketId, return (player offline)
       - Build QuestProgressPayload from questProgress and questDef
       - server.to(socketId).emit('quest:progress', payload)

    6. Update game.module.ts:
       - Import EventEmitterModule from '@nestjs/event-emitter'
       - Add EventEmitterModule.forRoot() to imports array (before other modules)
       - Import QuestService
       - Add QuestService to providers array
       - Add QuestService to exports array

    7. Wire server to QuestService in GameGateway.afterInit():
       - Inject QuestService in GameGateway constructor
       - Call questService.setServer(this.server) in afterInit()

    CRITICAL from research:
    - Emit entityId/speciesId NOT instance id (quests target species like 'creature_void_crawler')
    - Database update BEFORE WebSocket emit
    - try/catch in all @OnEvent handlers
    - Check obj.complete before incrementing
  </action>
