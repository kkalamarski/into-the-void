  <how-to-verify>
**Prerequisites:**
- Docker running (for database)
- Start all servers: `pnpm dev`

**Test 1: WASD Movement (MOV-01, MOV-03)**
1. Navigate to http://localhost:5173
2. Log in and select a character
3. Wait for game world to load
4. Press WASD or arrow keys
5. **Expected:** Player sprite moves IMMEDIATELY (no perceptible delay)
6. Try holding a key - should move continuously at ~150ms intervals

**Test 2: Click-to-Move (MOV-02)**
1. In the game world, click on a walkable tile several tiles away
2. **Expected:** Player pathfinds to the clicked location step-by-step
3. While pathfinding, press any WASD key
4. **Expected:** Pathfinding cancels immediately, WASD takes over
5. Click on a blocked tile (wall)
6. **Expected:** Nothing happens (no path found)

**Test 3: Server Validation (MOV-04)**
1. Move toward a wall using WASD
2. **Expected:** Player stops at the wall, cannot walk through
3. If prediction allowed walking into wall, position should snap back (reconciliation)

**Test 4: Network Events (NET-03, NET-04, NET-06)**
1. Open browser DevTools Network tab, filter by WS
2. Move with WASD
3. **Expected:** player:move events sent to server with sequence numbers
4. **Expected:** player:moved events received from server with lastProcessedInput
5. Check console for any reconciliation warnings

**Test 5: Connection Indicator**
1. Verify connection indicator shows in top-right
2. Movement should work with latency shown in indicator

**Optional: Two Browser Test**
1. Open a second browser/incognito with different account
2. Move one character while watching the other browser
3. **Expected:** Other player's movement appears smooth (tweened)
