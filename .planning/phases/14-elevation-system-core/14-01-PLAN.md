  <name>Task 2: Implement noise-based height variation</name>
  <files>packages/world-gen/src/generation/terrain.ts</files>
  <action>
Modify generateTerrain function to add noise-based height variation:

1. Create separate SimplexNoise instance for heights (different seed to avoid correlation):
   const heightNoise = new SimplexNoise(`${worldSeed}_height_${chunkX}_${chunkY}`);

2. In the tile loop, after determining tileId but before setting heights[y][x]:
   - Get base height from tileDef.defaultElevation (existing code)
   - Calculate height variation using FBM at higher frequency than terrain (0.08 vs 0.05):
     const heightValue = heightNoise.fbm(worldX * 0.08, worldY * 0.08, 3);
   - Convert to variance: const variance = Math.round(heightValue); // -1, 0, or +1
   - Calculate raw height: const rawHeight = baseHeight + variance;
   - Clamp to absolute range: const clampedAbsolute = Math.max(0, Math.min(5, rawHeight));
   - Clamp to biome range: heights[y][x] = clampToBiomeRange(clampedAbsolute, biome);

3. Update ensureZoneConnectivity to also clamp edge path heights to biome range.

IMPORTANT: Use SEPARATE noise instance (heightNoise) from terrain noise. Reusing terrain noise creates correlated height patterns (walls always same height).
  </action>

  </done>
