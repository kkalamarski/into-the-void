Modify npcStore.ts to add pending state management:

1. Add to NpcState interface:
   - `tradePending: boolean`
   - `questPending: boolean`
   - `setTradePending: (pending: boolean) => void`
   - `setQuestPending: (pending: boolean) => void`

2. Add initial state values:
   - `tradePending: false`
   - `questPending: false`

3. Add setter actions:
   - `setTradePending: (pending) => set({ tradePending: pending })`
   - `setQuestPending: (pending) => set({ questPending: pending })`

4. Modify `acceptQuest` to set pending BEFORE emit:
   ```typescript
   acceptQuest: (questId: string) => {
     set({ questPending: true });
     gameSocket.emit('quest:accept', { questId });
   }
   ```

5. Modify `completeQuestAtNpc` to set pending BEFORE emit:
   ```typescript
   completeQuestAtNpc: (questId: string) => {
     set({ questPending: true });
     gameSocket.emit('quest:complete', { questId });
   }
   ```

6. Modify `closeInteraction` to reset pending flags:
   ```typescript
   closeInteraction: () => set({
     interactingNpc: null,
     activeTab: 'dialogue',
     tradeError: null,
     tradePending: false,
     questPending: false,
   })
   ```

7. Modify the `trade:result` socket listener to:
   - Route errors to alertStore instead of inline tradeError
   - Reset tradePending on both success AND failure
   ```typescript
   import { useAlertStore } from './alertStore';

   gameSocket.on('trade:result', (data: { success: boolean; error?: string }) => {
     if (!data.success && data.error) {
       useAlertStore.getState().addAlert(data.error, 'error');
     }
     useNpcStore.getState().setTradeError(null);
     useNpcStore.getState().setTradePending(false);
   });
   ```

8. Add listener for `quest:accepted` event to reset questPending on success:
   ```typescript
   gameSocket.on('quest:accepted', () => {
     useNpcStore.getState().setQuestPending(false);
   });
   ```

9. Add listener for `quest:completed` event to reset questPending on success:
   ```typescript
   gameSocket.on('quest:completed', () => {
     useNpcStore.getState().setQuestPending(false);
   });
   ```

10. Add listener for `quest:error` event to handle failures:
    ```typescript
    gameSocket.on('quest:error', (data: { message: string }) => {
      useAlertStore.getState().addAlert(data.message, 'error');
      useNpcStore.getState().setQuestPending(false);
    });
    ```

CRITICAL: Set pending state BEFORE emit to prevent race condition where socket response arrives before state update.
