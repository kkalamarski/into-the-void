<task id="1">
<title>Write a programmatic map generator script for all 4 hub maps</title>
<details>
Create a TypeScript/Node.js script (packages/world-gen/src/maps/generate-hub-maps.ts) that programmatically generates all four 128x128 hub map JSON files. Writing 128x128 JSON by hand is impractical (16,384 tiles per array x 3 arrays), so use code.

The script should define room layouts for each hub and fill the tile/height/collision arrays accordingly. After running, it writes the 4 JSON files to packages/world-gen/src/maps/hubs/.

**Shared layout rules (from CONTEXT.md decisions):**
- 128x128 total size
- 8-tile thick wall perimeter around the entire map
- Docking bay (~20x20) along the south edge (centered, y=100-120 roughly) with portal tile at center
- Player entryPoint a few tiles north of the portal (not on it)
- 4-5 distinct rooms per hub connected by 3-4 tile wide corridors
- Doors are decorative (use door tile on corridor entry to room but non-blocking)
- Window tiles at intervals along perimeter walls
- ~15-20% accent floor tiles scattered on walkable areas

**Per-hub room layouts:**

CANOPY STATION (hub_verdant, tiles 30-37):
- Rooms: The Atrium (central, ~30x30), Trading Garden (NW, ~20x20), Docking Bay/The Threshold (south, ~20x20), Nursery/Service (NE, ~18x18), Communion Hall (SW, ~18x18)
- Style: Organic curved room edges (irregularly rounded corners instead of sharp 90-degree), vine corridors with accent moss tiles
- Atrium is the lore flagship room — central position

IRONHOLD STATION (hub_helix, tiles 38-45):
- Rooms: The Forge (north-center, ~25x25), Processing Bay 7/Docking (south, ~20x20), Armory/Trading (NW, ~20x18), Warren Rooms (multiple small ~12x12 rooms in east half), Engineering (SW, ~18x16)
- Style: Grid-like industrial layout, sharp right angles, narrow warren sub-rooms, metal grating accents
- The Forge is the lore flagship room

MERIDIAN STATION (hub_nexus, tiles 46-53):
- Rooms: The Exchange/Trading Floor (center-west, ~28x24), Welcome Center Alpha/Docking (south, ~22x20), The Archive (NE, ~20x18), Port Meridian/Service (NW, ~18x16), The Commons (east, ~20x18)
- Style: Symmetrical corporate layout, glass-style corridors (window tiles used as corridor decoration), clean
- The Exchange is the lore flagship room

SALVAGE STATION (hub_neutral, tiles 54-61):
- Rooms: Cargo Bay (center-south, ~24x22), The Docks/Docking Bay (south edge, ~20x18), Scrap Market (NW, ~20x18), Workshop/Service (NE, ~16x16), The Den/Faction Rep (SW, ~14x14)
- Style: Asymmetric patchwork, more hazard tiles (exposed wiring), uneven corridors (varying width 3-5), mismatched grating everywhere, fewer decorations, improvised feel
- Cargo Bay is the lore flagship room
- Rougher than other hubs — more hazard tiles, less symmetry

**For each hub the script must generate:**
1. `tiles[][]` — 128x128 with correct TileId values:
   - Perimeter: WALL tiles (8 tiles thick on all edges)
   - Perimeter intervals: WINDOW tiles (every 5-6 tiles along inner edge of perimeter wall)
   - Room interiors: FLOOR tiles with ~15-20% ACCENT tiles scattered randomly
   - Corridors: CORRIDOR tiles, 3-4 tiles wide
   - Room boundaries (internal walls): WALL tiles
   - Room entrances: DOOR tiles (1-2 tiles wide)
   - Decorations: DECORATION tiles (sparse in room centers, along walls, corridor intersections)
   - Hazard tiles: Sparse in most hubs, frequent in Salvage
   - Portal: Single PORTAL tile (16) at center of docking bay

2. `heights[][]` — 128x128:
   - 0 for floor/corridor/door/accent/hazard
   - 1 for decoration
   - 2 for wall/window

3. `collisions[][]` — 128x128:
   - true for wall, window, decoration (blocking)
   - false for floor, corridor, door, accent, hazard, portal

4. Metadata:
   - `zoneId`: hub zone ID string
   - `width`: 128, `height`: 128
   - `structures`: [], `spawnPoints`: []
   - `entryPoint`: { x, y } a few tiles north of the portal

**Important implementation details:**
- Use a seed-based pseudo-random for accent/decoration placement so maps are deterministic
- Round room shapes for Canopy (erode corners), sharp angles for Ironhold, symmetric for Meridian, irregular for Salvage
- Verify all rooms are reachable from the docking bay via corridors
- Ensure no corridor dead-ends or unreachable areas

Run the script with `npx tsx packages/world-gen/src/maps/generate-hub-maps.ts` and verify the output JSON files have correct dimensions and tile IDs.
</details>
