# Plan 130-02: Runtime PNG Guard and Visual System Verification

## Goal

Add a dev-mode `console.warn` guard that detects any unexpected tile PNG loading at runtime, verify the build compiles cleanly, and confirm all four visual systems (terrain cubes, weather, day/night, atmosphere) function correctly by reviewing the code integration points.

## Context

## Tasks

<task id="1">
### Task 1: Add runtime PNG tile loading guard

**File:** `apps/web/src/game/scenes/PreloadScene.ts`

**Steps:**

1. **Add a dev-mode guard in `loadAssets()`** that warns if any tile PNG is ever loaded. Place this at the end of the `loadAssets()` method, after all legitimate asset loading:

   ```typescript
   // Dev-mode guard: warn if any code path tries to load tile PNGs
   if (import.meta.env.DEV) {
     const originalLoadImage = this.load.image.bind(this.load);
     const originalLoadSpritesheet = this.load.spritesheet.bind(this.load);

     const tilePattern = /^tile_|^sprites\/tile_|void-tiles|crystal-tiles/;

     this.load.image = (...args: Parameters<typeof this.load.image>) => {
       const key = typeof args[0] === 'string' ? args[0] : '';
       const url = typeof args[1] === 'string' ? args[1] : '';
       if (tilePattern.test(key) || tilePattern.test(url)) {
         console.warn(`[PreloadScene] Unexpected tile PNG load detected: key="${key}" url="${url}"`);
       }
       return originalLoadImage(...args);
     };

     this.load.spritesheet = (...args: Parameters<typeof this.load.spritesheet>) => {
       const key = typeof args[0] === 'string' ? args[0] : '';
       const url = typeof args[1] === 'string' ? args[1] : '';
       if (tilePattern.test(key) || tilePattern.test(url)) {
         console.warn(`[PreloadScene] Unexpected tile PNG spritesheet load detected: key="${key}" url="${url}"`);
       }
       return originalLoadSpritesheet(...args);
     };
   }
   ```

   Place this **before** the first `this.load` call in `loadAssets()`, so it intercepts any tile PNG loading from any method called within `loadAssets()`.

**Verification:**
- The guard is wrapped in `import.meta.env.DEV` — zero overhead in production builds
- Pattern matches `tile_*` keys and `void-tiles`/`crystal-tiles` spritesheet keys
- Does NOT match feature spritesheets (`void-biome-features`, etc.) or quest markers (`ui_quest_marker`)
- The guard calls through to the original function (it warns but does not block)
</task>
