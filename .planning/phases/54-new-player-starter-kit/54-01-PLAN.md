Import crypto for UUID generation and define starter kit constants.

Add imports at top:

```typescript
import { randomUUID } from 'crypto';
```

Define starter kit item IDs as constants after imports:
```typescript
// Starter kit item definitions (Common rarity, Level 1)
const STARTER_SUIT_ID = 'suit_basic_common';
const STARTER_TOOL_ID = 'tool_combat_common';
```

In `createCharacter` method, modify the `createInventory` call to include initial equipment:

Change from:
```typescript
await createInventory(db, {
  characterId: character.id,
});
```

To:
```typescript
await createInventory(db, {
  characterId: character.id,
  equipment: {
    exosuit: {
      instanceId: randomUUID(),
      itemId: STARTER_SUIT_ID,
      quantity: 1,
      slot: -1, // equipped, not in inventory grid
      properties: {},
    },
    modules: [],
    tool: {
      instanceId: randomUUID(),
      itemId: STARTER_TOOL_ID,
      quantity: 1,
      slot: -1, // equipped, not in inventory grid
      properties: {},
    },
  },
});
```

This creates:
- Basic Exo-Suit (`suit_basic_common`) in exosuit slot
- Stun Rod (`tool_combat_common`) in tool slot

Both are Common rarity, Level 1 requirement items that any new character can use immediately.
