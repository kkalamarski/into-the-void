1. **Create `packages/database/src/schema/moderation.ts`** with two tables:

   **`player_mutes` table:**
   - `id`: uuid, primaryKey, defaultRandom
   - `characterId`: uuid, notNull, references `characters.id` with `onDelete: 'cascade'` (the player who muted)
   - `mutedCharacterId`: uuid, notNull, references `characters.id` with `onDelete: 'cascade'` (the muted player)
   - `createdAt`: timestamp with timezone, notNull, defaultNow
   - Add a unique constraint on `(characterId, mutedCharacterId)` to prevent duplicate mute entries. Use `.unique()` on the table or add a Drizzle `uniqueIndex`.

   **`player_blocks` table:**
   - `id`: uuid, primaryKey, defaultRandom
   - `characterId`: uuid, notNull, references `characters.id` with `onDelete: 'cascade'` (the player who blocked)
   - `blockedCharacterId`: uuid, notNull, references `characters.id` with `onDelete: 'cascade'` (the blocked player)
   - `createdAt`: timestamp with timezone, notNull, defaultNow
   - Add a unique constraint on `(characterId, blockedCharacterId)` to prevent duplicate block entries.

   Export inferred types: `PlayerMute`, `NewPlayerMute`, `PlayerBlock`, `NewPlayerBlock`.

   Use the Drizzle `unique()` helper from `drizzle-orm/pg-core` for composite unique constraints. Pattern:
   ```typescript
   import { pgTable, uuid, timestamp, unique } from 'drizzle-orm/pg-core';

   export const playerMutes = pgTable('player_mutes', {
     // ... columns
   }, (table) => [
     unique('player_mutes_unique').on(table.characterId, table.mutedCharacterId),
   ]);
   ```

2. **Update `packages/database/src/schema/index.ts`**: Add `export * from './moderation';` under a `// Moderation (MOD-04)` comment at the end.

3. **Create `packages/database/src/queries/moderation.ts`** with six functions:

   ```typescript
   import { eq, and } from 'drizzle-orm';
   import { DbClient } from '../client';
   import { playerMutes, PlayerMute, playerBlocks, PlayerBlock } from '../schema/moderation';
   ```

   - `addMute(db: DbClient, characterId: string, mutedCharacterId: string): Promise<PlayerMute>` — Insert into `playerMutes`, use `.onConflictDoNothing()` and `.returning()`. If conflict (already muted), do a select to return the existing row.
   - `removeMute(db: DbClient, characterId: string, mutedCharacterId: string): Promise<void>` — Delete where both columns match using `and(eq(...), eq(...))`.
   - `getMutes(db: DbClient, characterId: string): Promise<PlayerMute[]>` — Select all rows where `characterId` matches. These are the players that `characterId` has muted.
   - `addBlock(db: DbClient, characterId: string, blockedCharacterId: string): Promise<PlayerBlock>` — Same pattern as `addMute` but for `playerBlocks`.
   - `removeBlock(db: DbClient, characterId: string, blockedCharacterId: string): Promise<void>` — Same pattern as `removeMute` but for `playerBlocks`.
   - `getBlocks(db: DbClient, characterId: string): Promise<PlayerBlock[]>` — Same pattern as `getMutes` but for `playerBlocks`.

   Additional helper needed by Phase 105 (ChatService block enforcement):
   - `isBlocked(db: DbClient, characterId: string, blockedByCharacterId: string): Promise<boolean>` — Check if `blockedByCharacterId` has blocked `characterId`. Returns true if a row exists. This is the reverse lookup: "has player B blocked player A?"

4. **Update `packages/database/src/queries/index.ts`**: Add `export * from './moderation';`.
