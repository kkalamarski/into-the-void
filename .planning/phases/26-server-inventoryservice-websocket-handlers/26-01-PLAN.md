Implement these methods:

1. `async loadForPlayer(playerId: string): Promise<Inventory>` - Load from DB, create if not exists, cache in Map
2. `getInventory(playerId: string): Inventory | undefined` - Return cached inventory
3. `async flushAndUnload(playerId: string): Promise<void>` - Flush to DB, remove from Map
4. `async addItem(playerId: string, item: InventoryItemJson): Promise<{success: boolean; reason?: string}>` - Add item, check maxSlots, flush
5. `async removeItem(playerId: string, instanceId: string): Promise<{success: boolean; reason?: string; removedItem?: InventoryItemJson}>` - Remove by instanceId, return the removed item for drop handler
6. `async equipItem(playerId: string, instanceId: string, slot: keyof Omit<EquipmentJson, 'modules'>): Promise<{success: boolean; reason?: string}>` - Atomic move from items to equipment slot, use updateInventoryFull
7. `async equipModule(playerId: string, instanceId: string, maxModuleSlots: number): Promise<{success: boolean; reason?: string}>` - Add module to modules array
8. `async unequipItem(playerId: string, slot: keyof Omit<EquipmentJson, 'modules'>, inventoryCount: number, maxSlots: number): Promise<{success: boolean; reason?: string}>` - Move from slot to items, check inventory space
9. `async unequipModule(playerId: string, moduleInstanceId: string, inventoryCount: number, maxSlots: number): Promise<{success: boolean; reason?: string}>` - Remove from modules array

CRITICAL: All equip/unequip operations MUST use `updateInventoryFull` (single atomic DB write). Never call `updateInventoryItems` + `updateEquipment` separately.

CRITICAL: `removeItem` must return the removed item so `handleDrop` can spawn a ground entity with the correct itemId.
