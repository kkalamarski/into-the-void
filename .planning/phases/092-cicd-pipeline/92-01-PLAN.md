  <name>Task 1: Create GitHub Actions workflow for Docker image build and push</name>
  <files>.github/workflows/deploy.yml</files>
  <action>
Create GitHub Actions workflow file at `.github/workflows/deploy.yml` with the following configuration:

**Trigger:**
```yaml
on:
  push:
    tags:
      - 'v*'  # Match version tags like v1.19.0
```

**Environment variables at workflow level:**
```yaml
env:
  REGISTRY: ghcr.io
  IMAGE_PREFIX: ${{ github.repository }}
```

**Jobs structure:**

1. **build** job (matrix strategy for parallel builds):
   - Matrix: `service: [api, game-server, web]`
   - Runs on: `ubuntu-latest`

   Steps:
   a. Checkout code with `actions/checkout@v4`

   b. Set up Docker Buildx with `docker/setup-buildx-action@v3`

   c. Log in to GHCR with `docker/login-action@v3`:
      - registry: `${{ env.REGISTRY }}`
      - username: `${{ github.actor }}`
      - password: `${{ secrets.GITHUB_TOKEN }}`

   d. Extract metadata for tags with `docker/metadata-action@v5`:
      - images: `${{ env.REGISTRY }}/${{ env.IMAGE_PREFIX }}/${{ matrix.service }}`
      - tags: |
          type=semver,pattern={{version}}
          type=semver,pattern={{major}}.{{minor}}
          type=raw,value=latest

   e. Build and push with `docker/build-push-action@v5`:
      - context: `.` (full monorepo needed for NX build)
      - file: `apps/${{ matrix.service }}/Dockerfile`
      - push: `true`
      - tags: `${{ steps.meta.outputs.tags }}`
      - labels: `${{ steps.meta.outputs.labels }}`
      - cache-from: `type=gha`
      - cache-to: `type=gha,mode=max`
      - For web service only: build-args with VITE_API_URL and VITE_GAME_SERVER_URL from secrets

   f. Add build-args conditionally for web service:
      ```yaml
      build-args: |
        ${{ matrix.service == 'web' && format('VITE_API_URL=https://api.{0}', secrets.DOMAIN || 'intothevoid.online') || '' }}
        ${{ matrix.service == 'web' && format('VITE_GAME_SERVER_URL=wss://game.{0}', secrets.DOMAIN || 'intothevoid.online') || '' }}
      ```

**Permissions required at job level:**
```yaml
permissions:
  contents: read
  packages: write
```

**Concurrency to prevent duplicate runs:**
```yaml
concurrency:
  group: deploy-${{ github.ref }}
  cancel-in-progress: false
```

Key implementation details:
- Use matrix strategy for parallel image builds (all three run simultaneously)
- GITHUB_TOKEN has write:packages scope automatically for GHCR
- Build cache with GitHub Actions cache for faster subsequent builds
- Semantic versioning tags (v1.19.0 produces 1.19.0, 1.19, and latest tags)
- Full monorepo context is required because NX builds need all workspace packages
