Update MinimapCamera.ts to use correct isometric world dimensions:

1. Replace hardcoded `TILE_SIZE = 96` with isometric constants:
   ```typescript
   const ISO_TILE_WIDTH = 128;
   const ISO_TILE_HEIGHT = 64;
   ```

2. Update setBounds() calculation (line 33) to use isometric world size:
   - The isometric world in screen space extends differently than orthogonal
   - For a ZONE_SIZE x ZONE_SIZE grid in isometric:
     - Width: (ZONE_SIZE + ZONE_SIZE) * (ISO_TILE_WIDTH / 2) = ZONE_SIZE * ISO_TILE_WIDTH
     - Height: (ZONE_SIZE + ZONE_SIZE) * (ISO_TILE_HEIGHT / 2) = ZONE_SIZE * ISO_TILE_HEIGHT
   - Use: `setBounds(0, 0, ZONE_SIZE * ISO_TILE_WIDTH, ZONE_SIZE * ISO_TILE_HEIGHT)`

Note: The minimap remains orthogonal (showing an orthogonal view of the isometric world) - this is correct and matches standard isometric game patterns (Diablo, Starcraft). The camera follows the player container which is already positioned in isometric screen coordinates.

The player indicator rendering (updatePlayerIndicator) stays unchanged - it's positioned at screen-fixed minimap center (not world coordinates).
