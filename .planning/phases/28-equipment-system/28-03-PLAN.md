    2. Add Q key for tool swap:
       ```typescript
       // Tool swap hotkey
       const qKey = this.input.keyboard?.addKey(Phaser.Input.Keyboard.KeyCodes.Q);
       qKey?.on('down', () => {
         // Only swap if keyboard is enabled (not in UI panels)
         if (this.input.keyboard?.enabled) {
           import('../network/socket').then(({ gameSocket }) => {
             gameSocket.emit('equipment:tool_swap', {});
           });
         }
       });
       ```

    Alternatively, if there's already an input handling section, add to the existing key handler logic with a simpler pattern:
       - Import gameSocket at the top of the file (if not already): `import { gameSocket } from '../network/socket';`

         ```typescript
           if (this.input.keyboard?.enabled) {
             gameSocket.emit('equipment:tool_swap', {});
           }
         });
         ```

    The check for `this.input.keyboard?.enabled` ensures the swap doesn't trigger when typing in chat or when inventory/equipment panels are open (since they call setKeyboardEnabled(false)).
