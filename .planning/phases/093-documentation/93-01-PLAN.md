<task type="auto">
  <name>Task 3: Create GitHub Secrets reference</name>
  <files>docs/deployment/GITHUB_SECRETS.md</files>
  <action>
Create GitHub Secrets configuration guide covering:

1. **Required Repository Secrets** (for image builds)
   - None required - GITHUB_TOKEN provides automatic GHCR access

2. **Required Production Environment Secrets**
   - SSH_PRIVATE_KEY: SSH private key for Swarm manager (copy from `cat ~/.ssh/deploy_key`)
   - DEPLOY_HOST: IP address or hostname of Swarm manager
   - DEPLOY_USER: SSH username (root or deploy user)
   - POSTGRES_PASSWORD: Database password (generate with `openssl rand -base64 32`)
   - JWT_SECRET: JWT signing secret (generate with `openssl rand -base64 32`)

3. **Optional Secrets**
   - DOMAIN: Defaults to intothevoid.online if not set

4. **SSH Key Generation**
   - Generate key pair: `ssh-keygen -t ed25519 -f ~/.ssh/deploy_key -N ""`
   - Add public key to VM: `ssh-copy-id -i ~/.ssh/deploy_key.pub user@host`
   - Copy private key for secret: `cat ~/.ssh/deploy_key`

5. **GitHub Setup Steps**
   - Navigate to Settings -> Secrets and variables -> Actions
   - Create "production" environment
   - Add each secret with exact name

6. **Security Notes**
   - Never commit secrets to repository
   - Rotate secrets periodically
   - Use separate deploy user with limited permissions

Reference .github/workflows/deploy.yml for exact secret names used.
  </action>
