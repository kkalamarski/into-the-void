**EntityRenderer.ts changes:**

1. **Set `elevationOffset` to 0** (line 105):
   Change `private elevationOffset = 24;` to `private elevationOffset = 0;`
   This eliminates the root cause. Keeping the property at 0 (rather than removing it) avoids breaking the `container.setData('elevationOffset', this.elevationOffset)` downstream pattern.

2. **Set `spriteYOffset = 0` for all entity types** (lines ~208-224):
   Replace the entire spriteYOffset logic block:
   ```
   let spriteYOffset = -this.elevationOffset;
   if (this.isCreature(entity)) {
     spriteYOffset = 0;
     if (entity.speciesId && entity.speciesId in ANIMATED_CREATURE_Y_OFFSET) {
       spriteYOffset = ANIMATED_CREATURE_Y_OFFSET[entity.speciesId];
     }
   }
   if (this.isNpc(entity)) { spriteYOffset = 0; }
   if (this.isPlant(entity) || this.isMineral(entity)) { spriteYOffset = 0; }
   ```
   With:
   ```
   let spriteYOffset = 0;
   if (this.isCreature(entity) && entity.speciesId && entity.speciesId in ANIMATED_CREATURE_Y_OFFSET) {
     spriteYOffset = ANIMATED_CREATURE_Y_OFFSET[entity.speciesId];
   }
   ```
   This makes all entity types sit at y=0 (tile ground) by default, preserving the per-species override mechanism for animated creatures (all currently 0, but the mechanism stays for future use).

3. **Fix `uiBaseY` formula** (line ~281):
   Change `const uiBaseY = -this.elevationOffset - spriteHeight * 0.5;`
   To: `const uiBaseY = -spriteHeight;`

   Change `const markerY = -this.elevationOffset - spriteHeight * 0.5 - 60;`
   To: `const markerY = -spriteHeight - 60;`
