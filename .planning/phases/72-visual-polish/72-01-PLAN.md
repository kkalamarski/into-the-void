Add three new token categories to the existing :root block in global.css:

**Animation timing tokens:**
```css
/* Animation timing */
--duration-instant: 0ms;
--duration-fast: 100ms;
--duration-normal: 150ms;
--duration-moderate: 200ms;
--duration-slow: 300ms;

/* Easing curves */
--ease-out: cubic-bezier(0.33, 1, 0.68, 1);
--ease-in: cubic-bezier(0.32, 0, 0.67, 0);
--ease-in-out: cubic-bezier(0.65, 0, 0.35, 1);

/* Semantic transitions */
--transition-hover: var(--duration-normal) var(--ease-out);
--transition-active: var(--duration-fast) var(--ease-in);
--transition-modal: var(--duration-normal) var(--ease-out);
```

**Shadow elevation tokens:**
```css
/* Shadow elevation scale */
--shadow-0: none;
--shadow-1: 0 1px 3px rgba(0, 0, 0, 0.3);
--shadow-2: 0 4px 12px rgba(0, 0, 0, 0.4);
--shadow-3: 0 8px 24px rgba(0, 0, 0, 0.5);
--shadow-4: 0 12px 32px rgba(0, 0, 0, 0.6);

/* Semantic shadows */
--shadow-panel: var(--shadow-2);
--shadow-modal: var(--shadow-4);
--shadow-hover: var(--shadow-3);
```

**Glassmorphism tokens:**
```css
/* Glassmorphism */
--glass-blur: blur(10px);
--glass-tint: rgba(20, 20, 31, 0.7);

/* Modal backdrop */
--modal-backdrop-blur: var(--glass-blur);
--modal-backdrop-tint: var(--glass-tint);
```

**Accessibility - add at end of file (NOT inside :root):**
```css
/* Motion accessibility */
@media (prefers-reduced-motion: reduce) {

    --duration-instant: 0ms;
    --duration-fast: 0ms;
    --duration-normal: 0ms;
    --duration-moderate: 0ms;
    --duration-slow: 0ms;
  }
}
```

<task type="auto">
  <name>Task 2: Apply GPU-accelerated styles to buttons</name>
  <files>apps/web/src/styles/global.css</files>
  <action>
Update the existing .btn styles in global.css to use GPU-accelerated properties:

Replace the current .btn block with:
```css
/* Buttons */
.btn {
  padding: 8px 16px;
  border: none;
  border-radius: 4px;
  cursor: pointer;
  font-size: 14px;
  user-select: none;

  /* GPU-accelerated transitions */
  transition:
    transform var(--transition-hover),
    filter var(--transition-hover),
    box-shadow var(--transition-hover),
    background-color var(--transition-hover);
}

.btn:hover {
  transform: translateY(-1px);
  filter: brightness(1.15);
  box-shadow: var(--shadow-hover);
}

.btn:active {
  transform: translateY(0) scale(0.98);
  transition: transform var(--transition-active);
}

.btn:focus-visible {
  outline: 2px solid var(--color-accent);
  outline-offset: 2px;
  transform: translateY(-1px);
  filter: brightness(1.15);
}

.btn:disabled {
  opacity: 0.5;
  cursor: not-allowed;
  transform: none;
  filter: none;
}

.btn:disabled:hover,
.btn:disabled:active {
  transform: none;
  filter: none;
  box-shadow: none;
}

/* Touch devices - disable hover transforms */
@media (hover: none) {
  .btn:hover {
    transform: none;
    filter: none;
  }
}
```

Update .btn-primary and .btn-secondary to remove duplicate transition (already in base .btn):
```css
.btn-primary {
  background-color: var(--color-accent);

  background-color: var(--color-bg-tertiary);

}

.btn-secondary:hover {
  background-color: #2a2a3a;
}
```

Note: Remove `transition: background-color 0.2s;` from original .btn since the new transition property covers it.
