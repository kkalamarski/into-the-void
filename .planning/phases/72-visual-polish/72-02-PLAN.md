Add a new modal overlay class and update .npc-modal for fade-in effect. Add at the TOP of NpcInteractionModal.css (before .npc-modal):

```css
/* Modal overlay with glassmorphism */
.npc-modal-overlay {
  position: fixed;
  inset: 0;
  z-index: 99;
  display: flex;
  align-items: center;
  justify-content: center;

  /* Glassmorphism backdrop */
  background: var(--modal-backdrop-tint);
  backdrop-filter: var(--modal-backdrop-blur);
  -webkit-backdrop-filter: var(--modal-backdrop-blur);

  /* Create stacking context for backdrop-filter */
  isolation: isolate;

  /* Fade transition */
  opacity: 0;
  transition: opacity var(--transition-modal);
  pointer-events: none;
}

.npc-modal-overlay--visible {
  opacity: 1;
  pointer-events: auto;
}

/* Fallback for browsers without backdrop-filter */
@supports not (backdrop-filter: blur(10px)) {
  .npc-modal-overlay {
    background: rgba(10, 10, 15, 0.95);
  }
}
```
