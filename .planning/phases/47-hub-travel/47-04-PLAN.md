5. Import gameSocket if not already imported. TileId.PORTAL constant value is 16 — use the literal number with a comment.

Note: The server handles all validation. If the player is not on a portal tile, the server rejects the request. If they are in a hub, the server delegates to hub:leave. The client just needs to emit portal:use when arriving at tile 16.
