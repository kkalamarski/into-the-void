  <name>Task 1: Create computeCharStats pure function</name>
  <files>packages/game-logic/src/stats/char-stats.ts</files>
  <action>
Create new directory `packages/game-logic/src/stats/` and file `char-stats.ts`.

Implement:
1. Import types: `CharacterStats`, `StatScaleTarget` from `@into-the-void/shared-types`
2. Import `EquipmentJson` from `@into-the-void/database`
3. Import `ItemRegistry` from `@into-the-void/items`
4. Import `resolveEffectsForTrigger` from `../inventory/effects`

Define SCALE_CONSTANTS as a Record<StatScaleTarget, { base: CharacterStats; growth: CharacterStats }>:

Player constants:
- base: durability=100, toughness=50, power=50, haste=50, vigor=80, recovery=30, perception=40, resilience=30
- growth: durability=10, toughness=5, power=5, haste=3, vigor=7, recovery=3, perception=3, resilience=3

Creature constants (deliberately different for STAT-04):
- base: durability=80, toughness=40, power=60, haste=40, vigor=60, recovery=20, perception=50, resilience=25
- growth: durability=8, toughness=4, power=7, haste=4, vigor=6, recovery=2, perception=4, resilience=2

Implement `computeCharStats(level: number, equipment: EquipmentJson, target: StatScaleTarget = 'player'): CharacterStats`:
1. Get base and growth from SCALE_CONSTANTS[target]
2. Compute linear base stats: base + (level - 1) * growth for each stat
3. Collect equipped items: [equipment.exosuit, ...equipment.modules, equipment.tool, equipment.accessory1, equipment.accessory2].filter(Boolean)
4. For each item, get ItemRegistry.get(item.itemId), then resolveEffectsForTrigger for 'on_equip' and 'passive'
5. Aggregate bonuses: for each effect.applied entry, if key is in CharacterStats, add value to that stat
6. Return the final CharacterStats object

Pattern reference: See effectiveStats() in inventory/stats.ts for the exact aggregation pattern to follow.

IMPORTANT: Use `if (stat in stats)` guard when aggregating bonuses - silently skip unknown stat names (Phase 31 will map old buff names to new stats).
