  <name>Task 1: Add auto-attack loop to combatStore</name>
  <files>apps/web/src/store/combatStore.ts</files>
  <action>
    Extend the combatStore to manage an auto-attack interval timer. The auto-attack loop fires `basic_strike` at the selected creature target every ability cooldown cycle (1500ms for basic_strike) until:
    - The target dies (entity:update with active:false)
    - The target is deselected (selectTarget(null))
    - The player dies

    Add these fields and methods to the CombatState interface and implementation:

    1. Add field `autoAttackTimer: ReturnType<typeof setInterval> | null` (not serialized, runtime only)

    2. Add method `startAutoAttack(targetEntityId: string)`:
       - Clear any existing autoAttackTimer
       - Import `getEquippedAbilities` from `../store/abilityStore` and `useAbilityStore` from same
       - Import `useGameStore` from `../store/gameStore`
       - Fire ONE immediate `ability:use` emit for basic_strike (so first click attacks instantly)
       - Set an interval at 1500ms (basic_strike cooldown) that:
         a. Gets current state: player from gameStore, isCasting/isOnCooldown from abilityStore
         b. Checks player has enough energy (10 for basic_strike)
         c. Checks ability is not on cooldown
         d. Checks not currently casting
         e. Checks target is still selected and active (from entityStore)
         f. If all pass: emit `ability:use` with `{ abilityId: 'basic_strike', targetEntityId }`
         g. If target is dead/inactive or deselected: call `stopAutoAttack()`
       - Store interval handle in autoAttackTimer

    3. Add method `stopAutoAttack()`:
       - Clear the autoAttackTimer interval if it exists
       - Set autoAttackTimer to null

    4. Modify the existing `selectTarget` to call `stopAutoAttack()` when entityId changes or is null.

    5. Wire into existing socket listeners:
       - In the `entity:update` listener (line ~75): when selected target becomes inactive, call `stopAutoAttack()`
       - In the `combat:damage` listener: when target is killed, call `stopAutoAttack()`
       - In the `player:death` listener: call `stopAutoAttack()`

    **IMPORTANT**: The auto-attack interval must tolerate the ability being on cooldown gracefully — it just skips the tick and waits for the next interval. The server is the authority on whether the attack succeeds; the client just sends the request.

    **IMPORTANT**: Do NOT import `gameSocket` at the top level of combatStore if it already exists. Use the existing import. Similarly, reuse existing store imports.

    **2. Plant/Mineral click -> gather ability (lines ~434-447)**:
    In the `gameobjectdown` handler where `entityType === 'mineral' || entityType === 'plant'`, after selecting the target, automatically emit the gathering ability:
    ```typescript
    if (entityType === 'mineral' || entityType === 'plant') {
      this.lastClickedEntity = entityId;

      // Show target highlight
      const targetContainer = this.entitySprites.get(entityId);
      if (targetContainer) {
        this.targetHighlight?.show(entityId, targetContainer, 'herbivore');
      }

      // Set as target
      useCombatStore.getState().selectTarget(entityId);

      // Auto-trigger gathering ability (INTERACT-02)
      const abilities = getEquippedAbilities();
      let gatherAbilityId: string | undefined;
      if (entityType === 'plant') {
        gatherAbilityId = abilities.find(a => a.id === 'harvest')?.id
          ?? abilities.find(a => a.id === 'basic_harvest')?.id
          ?? abilities.find(a => a.id === 'gather')?.id;
      } else {
        gatherAbilityId = abilities.find(a => a.id === 'mine')?.id
          ?? abilities.find(a => a.id === 'basic_mine')?.id
          ?? abilities.find(a => a.id === 'gather')?.id;
      }
      if (gatherAbilityId) {
        const player = useGameStore.getState().player;
        const abilityDef = abilities.find(a => a.id === gatherAbilityId);
        const { isCasting, isOnCooldown } = useAbilityStore.getState();
        if (player && abilityDef && !isCasting() && !isOnCooldown(gatherAbilityId) && player.energy >= abilityDef.energyCost) {
          gameSocket.emit('ability:use', { abilityId: gatherAbilityId, targetEntityId: entityId });
        }
      }
      return;
    }
    ```
