Create `packages/game-logic/src/ai/creature-ai.ts` (new directory `ai/`):

1. Import dependencies:
   - `{ Creature, PlayerPublic, Position, ZONE_SIZE }` from '@into-the-void/shared-types'
   - `{ DIRECTION_VECTORS }` from '../movement/validation'
   - `{ chebyshevDistance }` from '../movement/pathfinding'

2. Export interface `AiTickResult`:
   ```typescript
   export interface AiTickResult {
     newPosition: Position | null; // null = creature did not move
   }
   ```

3. Export function `tickCreatureAI`:
   ```typescript
   export function tickCreatureAI(
     creature: Creature,
     players: PlayerPublic[],
     collisionMap: boolean[][],
   ): AiTickResult
   ```

   Implementation:
   - Guard: if `!creature.active || creature.health <= 0`, return `{ newPosition: null }`
   - Switch on `creature.behavior`:
     - `'herbivore'`: call `tickHerbivore(creature, players, collisionMap)`
     - `'omnivore' | 'predator' | 'maniac'`: call `tickWander(creature, collisionMap)`

4. Private function `tickHerbivore`:
   - `FLEE_RADIUS = 5` (Chebyshev distance)
   - Find players within radius:
     ```typescript
     const nearbyPlayers = players
       .map(p => ({
         player: p,
         dist: chebyshevDistance(creature.position.x, creature.position.y, p.position.x, p.position.y),
       }))
       .filter(({ dist }) => dist <= FLEE_RADIUS)
       .sort((a, b) => a.dist - b.dist);
     ```
   - If `nearbyPlayers.length > 0`: call `flee(creature, nearbyPlayers[0].player, collisionMap)`
   - Otherwise: call `tickWander(creature, collisionMap)`

5. Private function `flee`:
   - Calculate direction away from player:
     ```typescript
     const rawDx = creature.position.x - player.position.x;
     const rawDy = creature.position.y - player.position.y;
     const dx = rawDx === 0 ? 0 : rawDx > 0 ? 1 : -1;
     const dy = rawDy === 0 ? 0 : rawDy > 0 ? 1 : -1;
     ```
   - Build attempts array (flee direction first, then fallbacks):
     ```typescript
     const attempts = [
       { dx, dy },
       { dx, dy: 0 },
       { dx: 0, dy },
       { dx: -dx, dy: 0 }, // last-resort: partial backtrack
       { dx: 0, dy: -dy },
     ];
     ```
   - For each attempt, if `dx === 0 && dy === 0`, skip
   - Calculate `nx = creature.position.x + fdx`, `ny = creature.position.y + fdy`
   - Check bounds: `nx >= 0 && nx < ZONE_SIZE && ny >= 0 && ny < ZONE_SIZE`
   - Check collision: `!collisionMap[ny]?.[nx]`
   - If valid, return `{ newPosition: { ...creature.position, x: nx, y: ny } }`
   - If all attempts fail, return `{ newPosition: null }` (cornered)

6. Private function `tickWander`:
   - `WANDER_CHANCE = 0.25` (25% chance to move)
   - If `Math.random() > WANDER_CHANCE`, return `{ newPosition: null }`
   - Get directions from DIRECTION_VECTORS and shuffle:
     ```typescript
     const dirs = Object.values(DIRECTION_VECTORS);
     const shuffled = [...dirs].sort(() => Math.random() - 0.5);
     ```
   - For each direction, calculate `nx`, `ny`
   - Check bounds and collision same as flee
   - If valid, return `{ newPosition: { ...creature.position, x: nx, y: ny } }`
   - If none valid, return `{ newPosition: null }`
