Create `packages/game-logic/src/hazard/hazard.ts` with these pure functions:

1. **getHazardForBiome(biomeType: BiomeType): HazardConfig | null**
   - Returns `BIOME_HAZARD_MAP[biomeType] ?? null`

2. **isHazardousBiome(biomeType: BiomeType): boolean**
   - Returns `getHazardForBiome(biomeType) !== null`

3. **shouldApplyHazardTick(state: HazardState, now: number): boolean**
   - Returns false if `now - state.enteredAt < state.config.gracePeriodMs` (3-second grace period — HAZD-10)
   - Returns false if `now - state.lastTickAt < state.config.tickIntervalMs`
   - Returns true otherwise

4. **calculateHazardDamage(config: HazardConfig, maxHealth: number, protectionPercent: number): number**
   - If `config.hpDrainPercent === 0` return 0 (Tier II: debuff only)
   - Raw damage = `Math.ceil(maxHealth * config.hpDrainPercent)` (8% of max HP)
   - Effective damage = `Math.ceil(rawDamage * (1 - protectionPercent / 100))`
   - If protectionPercent >= 100, return 0 (fully immune — HAZD-05)
   - Returns effective damage (always >= 0)

5. **calculateHazardDebuff(config: HazardConfig, protectionPercent: number, stackCount: number): { stat: string; percent: number } | { stat: 'all'; percent: number }**
   - If protectionPercent >= 100, return `{ stat: 'none', percent: 0 }` (fully protected)
   - Look up debuff from HAZARD_GROUPS[config.hazardType]
   - basePercent = group.debuffPercent (0.20 for most, 0.15 for anomalous)
   - For anomalous with stacking: effectivePercent = basePercent + (stackCount * config.stackDebuffIncrease)
   - Apply protection reduction: finalPercent = effectivePercent * (1 - protectionPercent / 100)
   - Return `{ stat: group.debuffStat, percent: finalPercent }`

6. **calculateEffectiveHazard(config: HazardConfig, maxHealth: number, protectionPercent: number, stackCount: number): { damage: number; debuff: { stat: string; percent: number } }**
   - Combines calculateHazardDamage and calculateHazardDebuff
   - Returns both damage and debuff in one call

7. **shouldIncreaseStack(state: HazardState, now: number): boolean**
   - Only for Tier IV (config.stacksOverTime === true)
   - Returns true if `now - state.lastStackAt >= config.stackIntervalMs`
