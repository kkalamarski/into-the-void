Structure the document as follows:

**Header:**
```markdown
# Automation Tech Tree — Income/Sink Balance Sheet
**Created:** 2026-03-05
**Constraint:** Maintenance cost >= 60% of hourly output value per tier (AUTO-05)
**Status:** Design artifact — must be committed before automation code
```

**For each tier (T2 through T5), document:**

### T2 Extractor (AUTO-01)
- Level range: 10-20
- Player limit: 2 per player
- Output: 1 resource per 60 seconds (from resource node type)
- Duration: 5 minutes per fuel cell (5 resources total per cycle)
- Fuel: 1x Basic Fuel Cell per 5-minute cycle
- Resource output value: Common reagents ~30-35cr each, so 5 resources = ~150-175cr per cycle
- Fuel cell cost (crafting value): ~120cr (2x crystalline_dust at 30cr + 2x fungal_extract at 35cr = 130cr input)
- Maintenance ratio: 120/175 = ~69% (passes >= 60% rule)

### T3 Survey Beacon (AUTO-02)
- Level range: 20-30
- Player limit: 1 per player
- Output: 1 resource cache per hour (zone's dominant resource, quantity 3-5)
- Duration: 24 hours until degradation
- Fuel: 1x Advanced Fuel Cell per 4 hours (6 cells for full 24hr period)
- Resource output value: ~3 rare resources/4hr = ~600cr per fuel cycle
- Fuel cell cost: ~400cr (1x thermal_compound at 200cr + 1x crystalline_dust at 30cr + labor)
- Maintenance ratio: 400/600 = ~67% (passes >= 60% rule)

### T4 Planetary Extractor (AUTO-03)
- Level range: 30-40
- Player limit: 3 per player
- Output: 3-5 resources per hour (passive)
- Duration: Permanent with 10%/day degradation
- Fuel: 1x Power Core per 2 hours
- Resource output value: ~4 rare resources/2hr = ~800cr per fuel cycle
- Fuel cell cost: ~500cr (requires rare + epic reagents)
- Maintenance ratio: 500/800 = ~63% (passes >= 60% rule)

### T5 Refinery (AUTO-04)
- Level range: 40+
- Player limit: 1 per player
- Transmutation recipes:
  - 10 common -> 1 rare (30 min): input ~300cr, output ~200cr, net negative (sink)
  - 5 rare -> 1 epic (2 hr): input ~1000cr, output ~750cr, net negative (sink)
  - Cross-biome 10:1 (1 hr): input ~2000cr, output ~200cr, net negative (sink)
- Fuel: 1x Refinery Core per 2 hours
- Fuel cost: ~600cr
- Note: Refineries are deliberate credit sinks — output is LOWER value than input + fuel. Value comes from resource type conversion, not credit generation.
- Maintenance ratio: N/A — transmutation itself is the sink. Fuel adds additional cost on top.

**Summary table:**
```markdown
| Tier | Output/hr (cr) | Fuel/hr (cr) | Maintenance % | Passes? |
|------|----------------|--------------|---------------|---------|
| T2   | ~175           | ~120         | 69%           | YES     |
| T3   | ~150           | ~100         | 67%           | YES     |
| T4   | ~400           | ~250         | 63%           | YES     |
| T5   | Sink           | ~300         | N/A (net loss) | YES    |
```

**Key design notes:**
- Automation is a supplement to active play, not a replacement
- Higher tiers require rarer fuel, creating a progression gate
- Refineries are explicitly designed as resource conversion sinks, not generators
- PvP looting of accumulated resources adds further risk/reward

IMPORTANT: The exact credit values are approximate and serve as design constraints. The implementation should match these ratios, not exact numbers. Fuel cell costs must be tuned to maintain >= 60% ratio.
