   - Import `DamageType` and `DamageResistances` from `@into-the-void/shared-types`
   - Add exported constants: `RESISTANCE_FLOOR = 0.3` (70% max reduction per DMGT-03) and `RESISTANCE_CEILING = 1.5` (50% max vulnerability)
   - Add exported pure function `applyResistanceMultiplier(damage: number, damageType: DamageType, resistances: DamageResistances): number`:
     - Get resistance percentage from `resistances[damageType.toLowerCase() as keyof DamageResistances]`
     - Calculate raw multiplier: `1 - (resistPercent / 100)` (e.g., 60 => 0.4x)
     - Clamp to `[RESISTANCE_FLOOR, RESISTANCE_CEILING]` using Math.max/Math.min
     - Return `damage * clampedMultiplier`
   - Extend `DamageParams` interface with three OPTIONAL fields (backward-compatible):
     - `damageType?: DamageType`
     - `defenderResistances?: DamageResistances`
     - `damageBonusMultiplier?: number` (for damage_type_bonus gear effect)
   - Inside `calculateDamage()`, AFTER the armor reduction step and BEFORE the randomness step (between line ~158 and ~161 in current code), add:
     - If `params.damageType && params.defenderResistances`: call `applyResistanceMultiplier()` on the damage value
     - If `params.damageBonusMultiplier && params.damageBonusMultiplier > 1.0`: multiply damage by `params.damageBonusMultiplier`
   - The return type stays the same `{ damage: number; critical: boolean }` — no damageType in the return since the caller already knows it
