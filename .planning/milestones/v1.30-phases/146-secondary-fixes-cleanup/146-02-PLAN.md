# Plan 146-02: Remove debug logs and correct known-issues documentation

## Context

### Bug 1: Debug console.log in entity click handlers (MISC-03)

The `WorldScene.ts` `gameobjectdown` handler (lines ~416, 423, 428) contains three `console.log('[DEBUG]...')` statements that fire every time a player clicks an entity in the world. These pollute browser DevTools and should be removed from production code.

Additionally, the file contains numerous `console.log('[WorldScene]...')` and `console.log('[ChunkManager]...')` debug statements throughout the file. MISC-03 specifically targets the entity click handler logs, but all debug logs in production code should be cleaned up. The scope is:
- **Must remove**: The three `[DEBUG]` lines in `gameobjectdown` handler (lines ~416, 423, 428)
- **Should remove**: Other `console.log` statements in WorldScene.ts that are development debugging noise

### Bug 2: PROJECT.md known-issues stale entry (MISC-04)

The PROJECT.md Known Issues section currently contains:
```
- Adjacent chunk loading breaks on component remount (zone:chunk listener cleanup bug)
```

Phase 144 already fixed this bug (listener cleanup in GameContainer.tsx). The known-issues entry is now stale and should be removed since the issue is resolved. The requirement states the entry should accurately reflect the real bug -- since the bug is fixed, an inaccurate stale entry should be removed.
