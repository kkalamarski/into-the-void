<objective>
Fix two chunk loading bugs that cause black void areas in the open world:

1. **Listener cleanup bug (CHUNK-02):** GameContainer.tsx calls `gameSocket.off('zone:chunk')` without a handler reference, which deletes ALL zone:chunk handlers. After any React component remount (HMR, StrictMode double-mount, reconnection), the zone:chunk listener is silently removed and adjacent chunks never arrive.

2. **Failed chunk retry bug (CHUNK-01):** ChunkManager.ts keeps 'failed' entries in `chunkStates` permanently. When `queueChunkRequest` checks `this.chunkStates.has(zoneId)`, it returns true for failed chunks, so they are never re-requested. Returning to a previously-failed area leaves a permanent black void.

Purpose: Eliminate the primary causes of black void areas at chunk boundaries during normal gameplay.
Output: Two fixed source files — GameContainer.tsx and ChunkManager.ts.
</objective>

off<K extends keyof ServerEvents>(event: K, handler?: ServerEventHandler<K>): void {
  if (!handler) {
    delete this.handlers[event];  // <-- DELETES ALL handlers when no reference passed

}
