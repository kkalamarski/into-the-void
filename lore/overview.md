# A MMO survival sci-fi game

## Gameplay
2d isomprphic view, similar to Tibia / minecraft dungeons. Actually the goal is to mix the ideas from Tibia, No Mans Sky, World of Warcraft, Minecraft & minecraft dundeons.

Player would be a member of one of 3 factions, corporations that fight for influence over newly discovered planet, full of resources, new life forms, plants, minerals and artefacts.

Each faction should have a different vision, goals and morale values.

Players level up gaining experience by interacting with the world, discovering new species / materials, crafting gear, building houses / farms / factories. The PvP aspect of the game should be delicate - these are the corporations, they're not killing each other, but they may saboteur oposite factions.

World should be generated procedurally, we want to build as much diversity as possible, so that players can discover and explore the world. There will be structures that will spanw that will have a set map, as well as the main hub for each factory, and possible pvp arenas (we need to work on the lore & justification for pvp, so that it does not feel forced)
